# 子助手优化实施状态

## 目标与边界

依据 `docs/subagent-workflow-lifecycle-tech-design.md` 实施完成项分组、工作流层级、执行模型与预算、通知和收尾。主助手保留策略、安全、最终验收和配置授权；不采用 Agent Teams，不部署、不停止 Dashboard，不覆盖已有无关改动。

## 页面方向

面向日常使用者，优先回答谁在工作、哪里失败、结果在哪里。沿用现有主题与详情组件；成功和停止记录默认折叠，失败和待确认保持可见。工作流只占一个顶层入口，详情选中不因完成而跳变。窄屏可换行，状态带文字，不依赖颜色。

## 工作划分

1. 工作台/特性入口：共享任务状态投影，完成项分组、稳定详情、工作流进度和离线结果。
2. 主会话/侧栏：父子导航，工作流子助手去重，完成后保留历史入口。
3. 运行器：独立执行默认模型与选择信息、输入/交接预算、明确角色权限、重复通知与一次性任务收尾。
4. 主助手验收：差异检查、针对测试、同题模型基线、文档与部署交接。
