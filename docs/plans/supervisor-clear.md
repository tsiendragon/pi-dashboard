# 主助手清空会话

- 目标：用户点击“清空并重新加载”，建立空白主会话，自动重载资源和刷新界面。
- 保留：旧会话文件、本地任务、事件、截图；不重启服务或结束其他会话。
- 界面：沿用主管弹窗按钮样式；按钮旁明确保留范围；执行中禁用重复操作，忙碌或被接管时拒绝。
- 实现：监督扩展命令调用 Pi newSession（自动重载扩展）；网关只在清空期间接受新会话绑定；等待新会话连接后返回成功。
- 验收：后端 18 项、页面 31 项、监督扩展 24 项测试通过；两仓库相关类型检查通过。覆盖空白会话命令、空闲/并发保护、会话重新绑定、失败保留草稿及页面刷新。
- 未验证：真实进程的清空与重新连接、宽窄屏及主题视觉效果。没有构建前端或重启服务。
- 交接：用户执行 Dashboard `./run.sh` 生效；现存旧主会话需先结束并启动一次以加载新增命令，此后清空自动建立空白会话并重载资源。
