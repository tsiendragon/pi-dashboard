# Run Code 内部步骤显示

## 目标与设计
让查看会话的人一眼分清 Run Code 和其内部工具。沿用现有工具卡片、主题颜色与状态图标；父卡片默认显示缩进的内部步骤，可整体收起；内部步骤可分别展开，原始代码与汇总结果另外折叠。

## 范围
只改实时会话的工具归组与显示，不改运行时、服务接口或部署。使用运行时已有的 `<父调用编号>:code:<序号>` 关联格式；父调用必须确认为 run_code，独立工具保持原样。

## 验收
- 内部 Read、bash 只显示在所属 Run Code 下，不再平铺重复。
- 并行调用按开始顺序显示；运行、失败、成功和未收到结果的状态保留。
- 父卡片可整体收起；子卡片和代码结果可分别展开。
- 没有可靠关联的历史记录保持现状，不猜归属。
- 通过相关分组与组件测试；不由 agent 构建部署或重启服务。

## 完成与验证
- 已实现父卡片、缩进步骤、整体收起、单步详情及单独折叠的代码/结果；修正 Run Code 结果合并时丢失父调用显示入口的问题。
- 新增 14 个测试，覆盖并行顺序、多个父调用、无父调用消息的历史记录、独立工具、失败/运行/停止状态、流式更新和收起状态保留。
- 相关测试共 53 项通过；前端类型检查通过；差异空白检查通过。验证日志：`/tmp/pi-background/81871b8cb847dd82-314682/bash-cebf.log`。
