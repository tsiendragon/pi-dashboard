关键交互（请在 mock 里试）

① 跨会话节点 = 打开会话图谱上点 file A 的节点，直接跳到 A 的 agent session 并定位到那条消息。这是你要的“点开即打开对应 agent session”。
② 同会话节点 = 只选中点当前会话（file B）的节点不跳页，只在右侧看详情。避免浏览家族图时被反复弹出。
③ 会话页回图谱会话页左上「⛶ 在图谱中查看」，回到图谱并高亮该会话分组 + 选中该节点，形成闭环。
④ 未运行会话也能“打开”file A 没有 pi 进程 → 打开的是只读转录（数据就是家族解析的同一份 JSONL），输入框禁用并标“未运行”。
⑤ 取消泳道只剩分层布局（横轴 = 分支深度）。图/列表切换也已取消，只保留一个 graph 页。
⑥ 三种状态仍分离废弃分支（同文件，淡化）／未运行会话（会话级徽标）／未持久化（无 sessionFile）——语义与视觉都不同。
⑦ 写操作仍受 lease 控制「切到此处 / 从此分叉」在 L0 是置灰的；勾选「模拟 L2 写操作」后可用，并且切换后会出现撤销条。
⑧ 状态演示顶栏可切 家族降级 / 截断 / 未持久化 / navigate 失败，检查边界态。
