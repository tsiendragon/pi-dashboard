6 · 落地顺序（都在 ChatSidebar.tsx 内，后端零改动）

  • 切片 1 · 行 UI — 单行等高 + ellipsis + 相对时间 + 左沿状态条 + 主题化分隔线。风险最低，立刻见效。
  • 切片 2 · ⋯ 菜单 & tag 输入 — 三合一菜单、重命名、tag 联想补全、自动配色、系统 tag 命名空间（jobs.ts 一行改 job:8f2a）。
  • 切片 3 · 筛选条 — tagrail 聚合计数 + 点击筛选 + 分组 segmented + sticky 分组头。可选：历史（已结束）会话 tag 独立存储，需要新增后端文件，另议。

需要你拍板：① tag 是否也要覆盖历史会话 ② 要不要 📌 置顶 ③ 默认单行还是两行密度。
