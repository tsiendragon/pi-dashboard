# Android：逐机器 Dashboard 与手机功能边界

本文是产品/实现评估；安装、网络、构建与配对只以[部署指南](../guide/dashboard.md#android-live-pi22)为准。

## 信息架构

```text
机器列表（每项 = 用户配置的一个 Dashboard 连接）
└─ 本机 Dashboard
   ├─ Live Pi：搜索 → 置顶 / 网页任务分组 / 未分组 / Hold
   │  └─ Session：活动进度 / 完整对话 / 明确控制
   └─ 普通 Chat：独立 slot 列表与详情
```

不把多机器会话混成一个首页；进入 Dashboard 后，搜索、计数、新建、分组和详情均限定其 backend ID。
“机器”是已有连接配置，不代表发现了物理主机或自动扫描内网。两个连接即使返回同名分组、相同 sessionId，也不混用授权或数据。

2.2 / build 3 在机器列表、本机 Dashboard、服务器设置显示构建生成的实际 App 版本，不使用后端 `/api/status` 的服务版本。
机器页分开显示 Live 配对/连接、普通 Chat 连接；普通 Chat 已连接不代表已取得 Live 授权。

## 对齐 WebUI：已落地与后续范围

| 功能 | 手机适配判断 | 2.2 状态 / 边界 |
|---|---|---|
| 机器 → 本机 Dashboard → Session | 默认主流程 | 已实现；Live 默认，Chat 独立，不跨机器混列 |
| Live 在线列表、配对、cwd 新建、模型/思考等级 | 适合手机常用操作 | 已实现；roots 与入口授权不变，浏览不 claim |
| 标题/路径/模型/标签/分组搜索、工作中筛选 | 适合常驻 | 已实现；搜索当前授权在线列表，不冒充全历史全文检索 |
| 网页分组、置顶、保存的区块/会话顺序 | 适合常驻 | 已复用既有 groups/order/meta 接口；分组依 sessionId 保留；Hold 默认收起、搜索时展开 |
| 新建分组、移动/移出分组 | 适合轻量操作 | 已实现，与网页共用数据；仅组织元数据，不创建/中止 Pi、不抢租约、不自动重试 |
| 分组重命名/合并/删除、拖动排序 | 可以加，不是安全禁区 | 后续手机交互优化；本轮读取网页排序，写排序及上述管理暂用 WebUI |
| 活动卡、工具步骤、失败、完整对话 | 适合手机阅读 | 已实现保守投影；按真实用户消息分段，可展开完整记录，明确显示执行中/返回/失败 |
| 目标、当前阶段、工作项 done/total、阻塞 | 适合只读进度 | 已实现；来自结构化 goal anchor，展示“已标记完成”而非替用户验收 |
| 子 Agent / 工作流 / 长任务详情 | 应优先做只读移动摘要 | 本轮支持本机子 Agent 筛选并进入详情；父子可视关系、完整工作流卡/图谱后续做，不伪造状态 |
| 完整 Markdown、代码/表格、图片与产物预览 | 适合继续加入 | 目前文本可选择、thinking/工具可展开；完整排版及图片尚未加入；预览需大小限制和明确来源 |
| 历史 Session 列表与搜索 | 适合单独历史入口 | 尚未加入；不把历史 JSONL 当在线进程，不因点开历史自动恢复/启动 |
| 上下文、会话树、用量、模型详情 | 适合只读优先 | 上下文/树已有 JSON 预览；交互图谱与独立用量页后续适配 |
| 通知、语音、上传附件 | 可以加，需独立权限设计 | 尚未加入；通知应可禁正文，附件限制类型/体积/授权目录，不扩大默认授权 |
| 接管/释放、输入/引导/排队、模型切换 | 适合明确的会话操作 | 已实现；服务端租约、他端互斥与失败保留草稿不变 |
| 压缩/重载/重启/分叉 | 可以保留在二级菜单 | 已实现明确确认；服务端能力/状态校验继续有效，不批量影响工作会话 |
| 目标编辑、计划/工作项修改 | 可以加，但不应混同只读进度 | 本轮只读；以后需区分持久目标修改与发给 Agent 的消息，避免误改工作状态 |

### 活动进度不等于任务已验收

- `running` / `reconnecting` 直接取会话状态；工具执行状态取真实事件和最终 toolResult，不拿耗时推测百分比。
- 工具返回只表示该工具已返回；失败一直可见。没有最终回复、工具仍未确认、只收到 commentary/thinking 时，不标记整项完成。
- 最终回复只标「已回复」，不等于任务或测试通过。目标工作项计数取会话结构化记录，并提示明显陈旧/自相矛盾的目标状态。
- Native 活动分段是保守简化版，不宣称完整复刻 WebUI 的引用/批注归属、排队接手时机、计划步骤与工作流阶段推断。
- 时间线仍最多 1000 项、单条 65536 字符。活动标题/摘要是预览，可展开查看保留的记录；不偷偷把其余会话全文下载到手机。

## 不进入默认操作区的高风险能力

这些能力不应为了“对齐网页”就默认获得权限；其中有些可在将来以独立、受限入口加入，并非永远禁止：

- **PTY / 任意 shell、任意文件写入或主机管理**：不是会话列表的附带能力。需独立授权、明确机器/目录、输入确认、超时与审计；当前继续用已有 WebUI，不塞入全权限 WebView 或通用代理。
- **批量停止/强制接管/跨机器重启**：不作为首页快捷操作；不能绕过单会话租约和服务端状态限制。
- **扩展请求自动批准、后台自动发消息/claim**：不做。通知和只读浏览不能隐式取得控制权。
- **自动扫描内网、改 VPN/DNS/防火墙、开放公网**：不做。机器来自显式配置，连通也不等于应用授权。
- **复制主机控制 token、同步原始 Cookie/私钥、明文备份身份**：不做。配对仍是短期单次码与独立身份；不为方便扩大原有设备 grant 或 roots。

## 实施顺序与验收原则

1. **本轮核心**：逐机器导航、可见版本、Live/Chat 状态分离、搜索/分组/网页排序、保守活动视图与只读目标进度。
2. **后续阅读闭环**：完整 Markdown/产物预览、历史只读列表、父子 Agent 与工作流摘要、用量/图谱移动布局。
3. **再评估写能力**：分组完整管理与排序、目标编辑、附件/通知权限；主机管理/PTY 不与普通 Live 配对合并授权。

每轮先证明与现有 WebUI 使用同一真实数据，再验证手机交互；编译/JVM 测试不能代替真机 VPN、入口身份、配对和租约验收。
不得拿当前工作会话测试 abort/restart，也不得为排查手机版本反复重启 Dashboard。
