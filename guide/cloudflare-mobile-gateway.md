# 移动端远程接入状态

**尚未可部署。** 目标拓扑是各机器先加入入口机的 WireGuard 私网，再由机器侧连接器沿该私网主动向入口机建立出站 WSS 连接；届时工作机 Dashboard 须绑定 loopback（`PI_DASH_HOST=127.0.0.1`）并由主机防火墙阻断入站访问。手机不连接 WireGuard。私有入口端的接入与安全验收仍在进行；旧的按机器反代原型已归档。不要将 Cloudflare Tunnel 指向 Dashboard、实验网关或任何管理服务。

本仓库仅保留默认关闭、尚未部署的机器侧出站连接模块；旧入站网关验签适配已移除。出站模块只有在单独提供 0600 私有配置且 Dashboard 绑定 loopback 时才启用；目前提供脱敏的 live-session 标识和状态、可选的受限只读会话预览，以及握手完成后受限的会话租约声明、释放和文本输入控制。预览仅针对当前匹配的会话提供最近最多 8 条已完成的纯文本用户/助手消息；每条最多 512 UTF-8 字节，总体最多 6 KiB，不包含工具、思考、图片、路径或令牌字段（普通文字自身仍可能包含敏感信息，必须按授权设备保护）；会话不可用时不返回旧消息，也不持久化预览文本。控制消息采用固定字段和结果码，输入仅允许短文本、要求有效远程租约，超时及重复输入不自动重试；机器侧在 Pi 派发前持久预留 clientId + UUID 的散列，断线/失败也不删除。`$HOME/.pi-dashboard-private/machine-input-replay.json` 和独占 `.lock` 均须为当前用户所有的 0600 私有文件，`$HOME/.pi-dashboard-private/` 目录必须为 0700，家目录不得被组/其他用户写入；损坏、权限不安全、容量达到 100000 条时拒绝新输入，不自动淘汰。崩溃残留锁需核实进程退出后人工处理；文件不通过 HTTP/日志暴露，也不保存输入文本（详见 [config.md](config.md)）。断线时尽可能释放该连接的远程租约。它不提供 HTTP 代理、任意 Pi 命令、文件路径或图片传输能力。尚未配置 WireGuard 接入或私网 WSS 入口；多机器授权、撤销和控制的离线联调已经通过，真实设备、私网 TLS 入口与端到端网络隔离仍未验收。此仓库不包含实际入口地址、机器网络配置、设备配对材料或私有安全部署方案。待实现并通过安全验收后，才在本 `guide/` 增补通用安装说明。

服务由用户自行启动或重启；agent 不执行 `./run.sh` 或替用户部署。
