# PiDash Android 4.2 · build 23

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：极简 + iOS 视觉语言

4.1 把装饰全删了，结果偏"素"。本版按 Apple 的做法把该留的留下——极简指的是不加无意义的装饰，
不是不加层级。

**四条支点**（`ui/theme/Tokens.kt`）
1. **系统色**：`#007AFF` 强调（暗 `#0A84FF`）、分组底 `#F2F2F7` / `#1C1C1E`、发丝线 `#C6C6C8` / `#38383A`；
   文字用标签色 100% / 60% / 30% 不透明度，不用一堆灰阶。
2. **SF 字号**：正文 **17/25**（原 15）、headline 17 半粗、callout 16/23、subhead 15/21、
   footnote 13/18、caption 12/16、等宽 13/20 与 12/17、大标题 26/32。
3. **发丝线**：`0.5.dp`，分组列表内缩 16 dp。不再用 1 dp 硬线，也不再把分隔全部去掉。
4. **圆角连续性**：卡片 10、输入框 18、气泡 18（发送者侧收紧到 6）、sheet 14；
   Material `Shapes` 同步 8/10/12/14/16。

**具体变化**
- **自己的消息成为唯一实心色块**：强调色填充 + 白字 + 尾角 6 dp，和系统「讯息」一致。
  助手正文依旧纯文字，代码块用分组色圆角 10。
- **机器页 / 会话页改为 iOS 分组列表**：分组底（`#F2F2F7` / `#1C1C1E`）+ 白色圆角卡片 + 内缩发丝线；
  分组标题 13 sp 半粗大写。
- **输入框**：填充式、无边框、18 dp 圆角（关闭 Material indicator），左侧＋与右侧发送是 30 dp 圆形。
- **导航栏**：17 sp 半粗标题（两行截断）+ 下方一行事实 + 发丝线，去掉 pill 与粗分隔。
- 工具行内的展开列表改用发丝线分隔，步骤组头 13 sp 半粗。

设计稿 `docs/design-preview.html` 已整体换成 iOS 语言版本，含会话页与分组列表。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置与配对。
