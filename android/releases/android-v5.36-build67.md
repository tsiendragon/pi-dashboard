# PiDash Android 5.36 · build 67

Debug 预发布版，保持原有稳定签名；尚未完成真机验收。

## 设置页、Chat 页与弹窗对齐同一套语言

- **Header**：设置页、旧 Chat 页从 Material `TopAppBar` 换成 `CompactPageHeader`（48 dp 行高、20 dp 返回图标、标题 + 副标题，副标题会省略而不撑高）。设置页右下角由圆形 FAB 改成扩展「添加服务器」，与「新建会话」一致。
- **Tab**：新增 `SegmentedTabs`，列表页「Live Pi / Chat」、会话页「活动 / 完整」、设置页主题与字号共用它（48 dp 触控、选中态主题色）。不再一边下划线、一边胶囊。
- **输入框**：新增 `PiTextField`（填充底、14 dp 圆角、发丝边框、标签在框上方、可选密码掩码/多行/尾部动作），替换设置服务器表单、重命名、装扮的标题/表情/标签、模型搜索、目录搜索、扩展 UI 请求与 sudo 密码框。密码仍只做掩码，不新增复制/记录；sudo 的完成校验与按钮层级未改。
- **弹层**：会话行操作、模型/思考选择底部弹层圆角统一为 14 dp。
- **旧 Chat 页**：输入改成同一个一体式胶囊（无附件时左侧不占位），运行中胶囊右侧显示停止；消息气泡不变。

## Chat 新增「关闭会话」

- 右上角 ⋯ →「关闭会话…」，二次确认说明会结束该 Chat 的 Pi 进程、从列表移除并中断正在生成的回复，**磁盘上的会话记录不会被删除**，失败不自动重试。
- 确认后调用既有 `DELETE /api/chat/slots/:key`，成功后返回列表；失败保留对话框并显示原因。删除成功时本地同时清掉该会话的运行/流式状态并刷新列表。
- 这是破坏性操作，按钮用错误色；不做乐观关闭，避免把失败说成成功。
