# PiDash Android 5.17 · build 48

Debug 预发布版；尚未完成真机视觉与手势验收。

## 启动与返回

- 补上 Android 12+ 的系统闪屏：品牌图标配页面底色（深色模式下自动改为黑色背景），冷启动不再是白屏闪一下；没有引入新依赖，只用了平台属性。
- 打开预测性返回（`android:enableOnBackInvokedCallback`）：从会话返回列表时系统会跟手显示目标页面，而不是手势结束后才切换。

## 会话操作改为底部抽屉

- 列表行尾「⋯」和长按都不再弹出贴着小图标的下拉菜单，改为底部动作抽屉：整行 52 dp 高、带图标、拇指可达。
- 顺序为「重载扩展 / 重启 Pi 进程」→「改名 · 装扮 / 移动到分组」→ 排序模式下的「置顶本组 / 置顶」→ 最底部红色「关闭会话」；不可用时整行变浅灰。
- 排序模式下「↑ ↓」仍留在行尾，不额外增加一次点击。

## 与上一版的关系

- 5.16 的产物里已经包含 5.15 的下拉刷新、图片全屏查看（双指缩放）与可操作的空状态，本次没有重复列出；5.15 的更新说明文件已删除，避免出现一个从未发布的版本号。

## 验证与限制

- Android 编译通过，JVM 单测 206 项通过（含目录搜索相关用例）；沿用稳定签名，签名摘要与 `android/release-signing-cert.sha256` 一致。
- 尚未做真机或模拟器目视验收：闪屏图标在深色模式下的对比度、预测性返回与页内手势的配合、底部抽屉在全屏手势导航下的安全区留白，都需要在设备上确认。
