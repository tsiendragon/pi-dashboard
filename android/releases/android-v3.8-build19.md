# PiDash Android 3.8 · build 19

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：后台会话提醒（默认关闭）

「管理机器」页底部新增开关 **后台会话提醒**，默认关闭；Android 13+ 打开时会请求通知权限，
未授权会明确提示而不是假装成功。

只通知两件事（判定在 `notify/LiveAlerts.kt`，纯函数）：

| 事件 | 判定 | 标题 |
|---|---|---|
| 一轮回复结束 | `running → idle` | `已完成：<会话名>` |
| Agent 等待你回答 | pending UI 数量增加 | `需要你回答：<会话名>` |

- **隐私**：通知标题只含会话名与一句说明，正文**不含消息内容、命令、路径或 token**；锁屏不是可信面。
- **节流**：同一会话同一类事件 30 秒内只发一次；首次看到某会话不通知（避免启动时刷屏）。
- **没有前台服务**：提醒只在 App 进程仍存活且已退到后台时出现。进程被系统回收后不再提醒，
  也不会补发历史提醒。代价换来的是不申请 `FOREGROUND_SERVICE`、不维持常驻长连接。
- 通知点击回到 App；使用独立低优先级通道 `live_alerts`，可单独关闭。

4 项单测：完成只通知一次、新增待回答才通知、首次出现不通知、标题截断。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置与配对。
- 新增权限仅 `POST_NOTIFICATIONS`（可选授予）。
