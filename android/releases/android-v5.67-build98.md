# Android 5.67 (build 98)

## 合并远端更新

- 前台有阻塞的扩展请求时自动打开请求弹窗；输入框上方的审批卡片继续保留，作为请求弹窗之外的可见兜底。
- 自动打开只负责展示，不会自动批准、自动回答或自行发送文本；sudo 仍使用专用安全对话框。
- 执行步骤详情增加明确的执行状态，并支持分别复制命令、参数和输出。
- 远端 Dashboard 新增目标里程碑/当前动作分层视图；Android 目标弹窗本次仍按平铺清单展示，分层视图待接入。

## 本地 Android 修复/改进

- Feature clear 事件现在是权威状态，不会因 transcript 兜底把已清除的子 Agent/后台命令重新显示为运行中。
- 保留 5.66 的 Word 上传和 5.65 的会话路径复制。

## 验证

- Android 单元/截图测试通过。
- 前端测试仍为既有的 6 个失败（与本次合并前相同）；新增的 goal/extension UI 定向测试通过。
- 后端 goal 定向测试和前后端 typecheck 通过。
- 合并后的 Dashboard 侧 goal/前端改动需要按你的部署流程构建并重启；APK 只改 Android。
- Debug 预发布，尚未完成真机验收。
