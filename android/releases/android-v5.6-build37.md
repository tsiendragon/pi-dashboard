# PiDash Android 5.6 · build 37

Debug APK 预发布版，尚未完成真机端到端和视觉验收。

## 更新

- 收紧 Live Pi 顶栏、正文上下边距和输入区留白，为会话正文腾出空间；键盘收起时模型等操作仍可从「＋」菜单进入。
- 输入框保持紧凑，并在编辑较长草稿时自动增高；达到高度或行数上限后可滚动，不丢失草稿。
- 精简「＋」、发送按钮和输入框内字数的视觉尺寸，按钮仍保留 48 dp 点击区域；投递方式仍从「＋」菜单选择。
- 沿用已有签名，可覆盖安装旧版。

## 验证限制

- Android 构建及 JVM 单元测试通过；尚未在真机或模拟器验收。请检查长文本输入与滚动、键盘打开和收起、窄屏、大字体、投递方式与触控。
