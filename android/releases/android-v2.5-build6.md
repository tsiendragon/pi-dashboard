# PiDash Android 2.5 · build 6

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：让渲染与 WebUI 的排版规则一致

- **工具步骤改为一行式步骤条**：状态图标 + 已完成/进行中/失败/受阻 + 工具名 + 单行摘要，
  与 WebUI `ActivityTimeline` 的 `StepList` 一致。参数与完整输出**默认折叠**，点「展开输出」才显示。
- **Run Code 单独归组**：`run_code` 一类工具标为「Run Code」，折叠入口为「展开 Run Code」，
  不再把整段脚本与输出混在正文里。
- **长正文按 WebUI 规则截断**：超过 12 行或 1200 字先显示预览，底部渐变，按钮文案
  「展开全部正文（N 行）」/「收起正文」，阈値取自 `ActivityReplyBody`。
- 图片附件仍按真实数据 URL 显示；渲染页面依旧离线、无网络、无凭据。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置；签名不符不要卸载绕过。
- 仍需原有私有 HTTPS 入口授权与网页一次性配对码；下载 APK 不等于取得服务器权限。
- 本版只改 App，服务端不需要重启。

## 已验证与限制

- 73 项 Android JVM 单元测试通过；APK 构建、包版本与签名已核验。
- 手机实机排版、IME、VPN 双层认证、WebView 渲染仍待真机验收。
