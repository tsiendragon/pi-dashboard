# PiDash Android 5.29 · build 60

Debug 预发布版；真实桌面图标与手机冷启动仍待验收。

## 新 App 图标

- 以深墨渐变底、暖橙 π 和青绿终端光标替换原有白底黑色图标；定制圆润的几何字形，不依赖系统字体，不加入小字或复杂装饰。
- 背景与前景分层，圆形/圆角方形等最终轮廓交由 Android 桌面裁切；前景位于 66 dp 自适应图标安全圆内。
- Android 13+ 增加同轮廓的 monochrome 主题图标；需桌面支持/启用，颜色由系统与壁纸决定。
- Android 12+ 启动画面沿用原有明暗页面背景，仅为新图标提供深墨色底，保持清晰与品牌一致。
- 仅修改 Android 图标与启动图标资源，不改网页/桌面客户端，不改应用名称、包名、权限、连接配置或业务流程。

## 验证

- 266 项 JVM 测试、23 张截图回归及 Debug APK 构建通过。
- 新增普通图标/主题图标两张预览，覆盖模拟圆形/圆角方形、测试平台默认裁切及 24/32/48 dp；已查看渲染结果，不等同于厂商桌面或真机验收。
- 校验前景全部落在安全圆、彩色/单色轮廓一致、标准/round 资源一致、24 px 原生渲染保留 π 与光标，以及明暗启动页的品牌图标底。
- 发布脚本核验原有稳定签名、版本、测试及产物新鲜度，公开 APK、SHA256SUMS、build-info.json；`phoneEndToEndVerified` 保持 false。

## 安装

同签名覆盖安装即可，无需重启 Dashboard 或 `/reload`。若桌面图标缓存未刷新，可移除桌面快捷方式后重新添加，不要卸载 App 或清除数据。agent 未重启服务。
