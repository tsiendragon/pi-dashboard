# PiDash Android 5.4 · build 35

Debug APK 预发布版，尚未完成真机端到端和视觉验收。

## 更新

- Live Pi 不编辑时收起模型、思考强度与快捷提示工具行，腾出正文空间；这些操作仍可从「＋」菜单进入，开始编辑时工具行重新显示，草稿不会丢失或被快捷提示覆盖。
- 「查看详情」页压缩用户消息气泡，将引用、批注、分叉和长消息展开等操作收进消息菜单，保留触控区域。
- 用户消息和输入文字略微缩小，继续遵循系统和 App 字号设置；Agent 正文字号不变。
- 沿用已有签名，可覆盖安装旧版。

## 验证限制

- Android 构建及 JVM 单元测试通过；尚未在真机或模拟器验收。请重点检查窄屏、大字体、键盘打开和收起、草稿、消息菜单以及长消息展开。
