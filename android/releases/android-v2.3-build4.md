# PiDash Android 2.3 · build 4

**Debug APK 预发布版**，尚未完成真机端到端验收；不是应用商店正式版本。

## 本版重点

- **正文用 WebUI 自己的渲染器**：Markdown、GFM 表格、代码高亮、公式、mermaid 图形、diff、图片
  与网页同一套 React 组件与主题色，不再由 Kotlin 近似实现。渲染器离线打包进 APK，
  无网络、无 Cookie、无凭据；加载失败自动回退「原生文本」。
- **输入不再需要“接管”**：普通消息、改标题、切模型、重载扩展与 WebUI 规则一致，手机、网页和
  TUI 可以同时对同一会话输入。只有中止、压缩、重启要求显式接管，他端持有时直接拒绝。
- 会话页三档视图：`WebUI 渲染` / `原生文本` / `活动进度`；活动进度仍只读展示目标、工作项与阻塞。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置；签名不符时不要卸载绕过。
- 仍需原有私有网络/HTTPS 入口授权与网页生成的一次性手机配对码；下载 APK 不等于取得服务器权限。
- 本版只改 App；2.1 起已有配对与分组接口的服务端**不需要重启**。

## 已验证与限制

- 66 项 Android JVM 单元测试通过（含渲染载荷契约与“输入不取租约”回归）；APK 构建、包版本、签名核验通过。
- 手机 VPN/双层认证、实际配对、WebView 实机排版、IME、租约互斥仍待真机验收。
- 活动分组仍是保守的移动端投影，未逐字复刻 WebUI 的引用/批注/排队接手归属；完整工作流图谱、
  历史搜索、文件/上传、PTY、目标编辑、用量页、语音、后台通知尚未加入。
