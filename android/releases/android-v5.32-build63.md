# PiDash Android 5.32 · build 63

Debug 预发布版，保持原有稳定签名；尚未完成真机验收。

## 会话内容页改为底部上拉刷新

- Live 活动和完整对话视图不再下拉刷新。到达最新消息后，继续向上拖动约 96 dp，看到「松开刷新」再松手同步会话。
- 仅使用底部未被内容消费的手指拖动；中间阅读、未拉足或回拉后松手、惯性滑到末尾不刷新。刷新期间不重复提交；切换会话/模式清除未释放的拖拽。
- 空消息及初次同步占位支持上拉重试，保留原有中心布局。
- 底部以主题色进度和文字反馈，不反转页面、不平移正文、不改变时间顺序或插入影响滚动索引的列表项。用户在刷新中查看历史时提示移至内容区顶部，避开「回到最新」，不强制跳回底部。
- 刷新失败沿用原因提示，状态在 finally 中恢复；保留菜单「刷新」入口并避免与手势刷新并发。
- 长按选择、复制文字/整条消息及原有阅读跟随策略保留。机器的会话列表页仍下拉刷新；未改旧 Chat、活动详情弹窗、后端或协议。

- 329 项 Android JVM 测试全部通过，无失败、错误或跳过；30 张截图回归与 Debug APK 构建通过。
