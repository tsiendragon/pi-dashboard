# PiDash Android 3.9 · build 20

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：视觉系统重做（会话页）

之前用的是 Material 3 默认配色 + Android 12 壁纸取色，于是用户气泡颜色取决于壁纸、整页几乎全是
同一个 `labelSmall` 字号。本版建立自己的设计 token 并重画会话页。

**设计 token**（`ui/theme/Tokens.kt`）
- 配色：一套中性底 + 单一强调色（亮 `#1F6FEB` / 暗 `#6FA8FF`）+ 成功/错误；壁纸动态取色**默认关闭**。
- 字号：正文 15/23、紧凑 14/21、元信息 13/19、微 11/15、标题 16/22 半粗、等宽 13/20 与 12/18。
- 间距 4 dp 栅格（4/8/12/16/24）；圆角 6/12/16 三档；正文限宽 720 dp。

**会话页**
- 头部：标题最多两行 + 一排 pill（状态、模型、思考、上下文 %、目标状态）+ 一行 cwd 省略；
  原来三行 labelSmall 的「日志感」去掉。AppBar 与页面同色，不再有一条生硬分隔。
- 消息：用户=强调色 12% 底 + 16 dp 圆角靠右（不再随机粉色）；助手正文 15/23 无底色；
  错误改为红色细边 + 6% 底而不是整块红。
- 工具行：6 dp 状态圆点替代文字 ✓；工具名 mono 半粗、参数 mono 12 灰、`⌄/⌃` 展开；
  输出框改为细边框 + 等宽正文；步骤组用一条细竖线挂步骤，组头是「N 个步骤 + 状态 + 工具名」。
- 代码块：细边框替代填充块，24 dp 头部（语言 chip + 复制），等宽 13/20，块内横滚不变。
- 输入区：状态行（圆点 + 一句状态 + 中止）压成一行，`默认/引导/排队` 三个 chip 收进
  「投递：默认 ▾」菜单，输入框圆角 12、正文 14，右侧只留字数。

**设计稿**：`docs/design-preview.html` 用同一套色值/字号/间距重画了这五块，可在浏览器里对照明暗两版。
它是设计稿不是 App 截图，真机字体度量会有差异。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置与配对。

## 已验证与限制

- 135 项 Android JVM 单元测试通过；APK 构建、包版本、签名核验通过。
- **纯视觉改动，没有真机验证**：暗色下强调色与代码配色的对比度、中文行距、系统大字号下的换行都需要真机确认。
- 机器列表页、各对话框尚未套用新 token，计划下一版跟进。
