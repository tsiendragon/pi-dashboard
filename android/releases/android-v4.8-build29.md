# PiDash Android 4.8 · build 29

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版更新：按照移动端原型调整会话界面

1. **会话列表卡片（`LiveSessionsPanel`）**
   - 每条会话卡片新增序号、**可点击的表情 + 标记颜色头像框**（点击直接打开会话装扮与改名弹窗）。
   - 每条会话卡片底部常驻快捷操作栏：**`↑` 上移、`↓` 下移、`🔄 重载`、`⚡ 重启`（含二次确认弹窗）、`✏️ 改名/装扮`、`📁 分组`**；开启 `↕️ 排序模式` 时额外显示 `⤒ 置顶本组` 与 `📌 置顶`。
2. **单会话页顶栏、子栏与底部 Composer（`LiveSessionScreen`）**
   - 顶栏固定显示（不再因滚动隐藏）：左侧为可点击的**表情/颜色头像 + 标题 + 项目与模型副标题**（点击直接改名与设置表情/颜色）；右侧常驻 **`[🔄 重载]`** 与 **`[⚡ 重启]`** 胶囊按钮。
   - 顶栏下方新增辅助子栏：左侧为 **`🎯 目标` 胶囊**，右侧为 **`[活动 | 完整]` 分段切换开关**。
   - 底部输入框上方新增**快捷提示词横滑条**（交接存档、收尾自查、新 session 接续、验收前检查）以及 **`[🤖 模型 ▾]`** 与 **`[💭 思考: level ▾]`** 快捷切换栏。
3. **WebUI 风格活动卡片（`NativeActivityCard`）**
   - 活动卡片升级为完整三段式结构：**顶部用户请求头栏**（`👤 用户请求` 徽标 + 提问正文）、**中部可折叠 `📋 进度说明`、`⚡ 执行步骤 (N 步)`、`💭 思考过程`、引用/批注追问与直接渲染的 Markdown 回复正文**、**底部状态徽标与详情/引用入口**。
4. **装扮弹窗、模型分组卡片与思考等级能量阶梯（`LiveDialogs`）**
   - 装扮弹窗合并**会话标题重命名、9 色预设圆点、5 大分类表情网格选择器、自定义表情、置顶与标签**。
   - 思考强度升级为 **7 档阶梯式能量条卡片**（`关 · Off` 至 `最高 · Max`，含场景说明与推荐标记）。
   - 模型选择升级为**搜索 + 特性筛选芯片（`全部` / `🧠 支持思考` / `📦 200K+ 上下文`）+ 服务商分组卡片 + 能力胶囊（思考档位、上下文容量）**。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；使用现有稳定签名，可直接覆盖安装并保留本地服务器配置与登录 Cookie。
