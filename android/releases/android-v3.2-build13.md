# PiDash Android 3.2 · build 13

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：活动分组 + 引用/批注

- **活动分组**：连续的工具调用不再一条条平铺，折叠成一行
  `✓ 3 个步骤 · 已完成  bash · read · write`；点「展开」看每一步，含失败显示 `! 含失败`、执行中显示 `● 进行中`。
  单次调用仍是一行，不会因为分组而变成另一张卡片。
- **引用**：消息下方「引用」把该条正文折叠空白、截到 160 字后加成待发送芯片（最多 4 段），
  发送时按网页同款格式前置：`引用（来自你的回复）：` + 逐行 `> 引用内容`。
- **批注**：在引用基础上再写一段评论，发送时组成网页同款 review 消息：
  `Please review and address these comments about the quoted parts of our conversation:`，逐条
  `[1] 你的回复` / `Quoted: "…"` / `Comment: …`。
- 引用/批注芯片可单独移除；发送失败时草稿、附件、引用、批注全部保留。

格式与网页 `frontend/src/utils/reviewComments.ts` 逐字节一致，Agent 在两个客户端读到同一形状。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置与配对。
- 仍需原有私有 HTTPS 入口授权 + 网页一次性配对码。
