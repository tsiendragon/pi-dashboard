# Android 5.61 (build 92)

- 修复后台完成提醒：此前退到后台会立即断开 Live 连接，通知 watcher 看不到 `running → idle`，因此经常收不到“回复结束”通知。
- 只要仍有运行中的回合或待处理请求，App 在后台会保留 Live 连接；收到结束/停止后发通知，所有会话空闲约 3 秒后断开。
- 提醒改为观察会话列表，不再只依赖当前打开的对话详情。
- 完成通知正文增加“点按查看回复”，并提供“查看回复”动作；sudo/自由文本等无法在通知栏直接回答的请求提供“打开会话”。
- 点击通知或动作直接进入对应 Live 会话；已有 App 任务用 `singleTop` 复用，避免重复创建页面或丢失深链。
- 通知仍默认关闭，需要在设置中开启；没有前台服务，进程被系统回收后不会补发，系统冻结后台网络时也可能延迟。
- 仅改 Android App，覆盖安装即可；Debug 预发布，尚未完成真机验收。
