# PiDash Android 5.33 · build 64

Debug 预发布版，保持原有稳定签名；尚未完成真机验收。

## 呼吸灯表示“正在运行”

- 会话列表行、会话页标题区、输入框上方的「运行中」，以及执行中的工具行，改用同一个呼吸动画小圆点：900 ms 在 100% 与 35% 不透明度之间往返，表示此刻确实有工作在跑。
- 空闲、已完成、失败、断连和缓存状态继续用静态圆点或不显示，不再用同一个静态点同时表达“运行中”和“静止”，减少误读。
- 活动卡片与活动详情顶部原有的状态胶囊本就是呼吸点，本次只是把它抽成共享组件，两处外观保持一致。
- 尊重系统「移除动画」无障碍设置（全局动画时长为 0）：动画关闭时圆点保持不透明常亮，仍能标记运行中，也不会持续耗电刷新。
- 动画不是唯一信号：现有文字标签（运行中、执行命令、思考中）和列表行的无障碍描述「运行中」同时提供状态；纯装饰位置不加朗读节点。
- 断连/本机缓存提示仍是判断数据新鲜度的依据：呼吸灯只反映收到的最后状态，不代表已连上服务器，也不代表命令成功。

## 验证

- 新增纯函数测试验证呼吸曲线端点与边界（关闭动画恒为不透明；开启时 0→100%、0.5→67.5%、1→35%），以及系统动画时长 0 时确实判定为关闭动画。
- 新增 Compose 测试验证圆点尺寸、可选的「运行中」无障碍名称、无描述时不产生多余朗读节点。
- 335 项 Android JVM 测试、30 张截图回归与 Debug APK 构建通过；组件截图与模拟时钟不代表真机动画节奏、抬手/降级动画或厂商系统表现。

## 安装

覆盖安装即可，无需重启 Dashboard 或重载扩展；未改后端、协议或配置。
