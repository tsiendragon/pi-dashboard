# PiDash Android 5.30 · build 61

Debug 预发布版；真机文字选择、剪贴板及选择手柄/放大镜仍待验收。

## 文字选择与复制

- 修复普通 Markdown 正文缺少选择容器的问题，支持长按选词；普通段落不再安装无用的点击拦截，链接与文件路径保持短按打开、长按选择。
- 活动卡片底部新增「复制」菜单，可复制完整回复、请求、思考与进度；点击复制不会误开详情。
- 用户/助手消息「⋮」新增复制文字/正文/思考；短消息、只读或未接管会话同样可用。独立思考展开后也有复制入口。
- 工具展开后提供「复制思考 / 参数 / 输出」，按原顺序保留合并的思考，复制参数不受展示用的 65536 字符截断限制，输出保留原始空格与换行。
- 复制当前已加载的完整原文，不只复制折叠预览；整条正文保留 Markdown，长按选区复制渲染文字。不能恢复服务端/缓存已裁剪或未加载的内容。
- 代码复制与其他复制按钮使用至少 48 dp 点击区域，主题色标识操作，复制后有反馈；系统失败时提示重试/缩小选区，不静默截断。
- 复制仅由明确点击/系统选择触发，不自动读取、记录或上传剪贴板，不为 sudo 密码字段增加复制功能。系统剪贴板不属于 App 加密缓存，敏感内容需留意系统和输入法规则。

## 验证

- 290 项 Android JVM 测试、26 张截图回归及 Debug APK 构建通过；新增明暗与 200% 字号下的真实消息/工具复制控件截图，已查看结果，不代表整页或手机验收。
- 验证长按选词、链接长按不打开/短按仍打开、可点击活动标题内的文字选择；完整复制折叠原文、只读消息、长参数、输出空白、思考重复/顺序、代码内容、点击高度与成功反馈。
- 验证渲染时不改动已有剪贴板，空内容/不可用剪贴板不擦除原内容，复制活动回复不触发导航。
- 长按测试使用模拟文本工具栏验证复制回调与实际 Robolectric 剪贴板；原生放大镜因测试环境没有 Surface 而仅在测试中替换为无绘制实现，不能视为真实手柄/放大镜验收。
- 发布脚本核验版本、原有稳定签名、测试及产物新鲜度，公开 APK、SHA256SUMS、build-info.json；手机验收标记保持 false。
