# PiDash Android 2.2 · build 3

本版本为 **Debug APK 预发布版**，尚未完成真机端到端验收；不是应用商店正式版本。

## 页面与功能

- 首页按机器列出 Dashboard、来源地址、Live 配对/连接状态、在线主会话与工作中数量；普通 Chat 连接状态单独显示。
- 导航为「机器 → 本机 Dashboard → Session」。本机默认 Live Pi，普通 Chat 独立保留，不跨机器混列。
- Live 支持按标题、路径、模型、分组、标签搜索，工作中和子 Agent 筛选；与网页共用分组、置顶/标签和保存的排序，Hold 默认折叠。
- 可新建分组、移动/移出会话；可在允许的工作目录新建真实 Live Pi。
- Session 可切换「活动进度 / 完整对话」，展示流式文本、思考、工具步骤/结果/失败；只读目标、当前阶段、工作项计数和阻塞。
- 支持明确接管/释放、输入/引导/排队、中止、模型/思考等级、标题及置顶/标签设置。压缩/重载/重启/真实条目分叉需明确确认。
- 机器列表、Dashboard 与设置页显示 `v2.2 · build 3`。

## 安装与授权

- 包名仍为 `com.sam.pidash`，minSdk 26；同签名覆盖安装可保留配置。签名不匹配时不要卸载来绕过，应先核对来源。
- 仍需原有私有网络/HTTPS 入口授权，以及网页 Live「手机配对」生成的一次性码；下载 APK 不代表取得服务器权限。
- APK 不含设备配置、入口凭据、Cookie 或签名私钥。查看列表/打开会话只读，不自动接管。
- 已有配对与分组接口的服务端无需为本轮重启。GitHub 发布不等于 App 内自动更新，仍由用户下载并确认安装。
