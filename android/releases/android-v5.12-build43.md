# PiDash Android 5.12 · build 43

Debug APK 预发布版，尚未完成真机端到端和视觉验收。

## 更新

- Live Pi 会话列表更紧凑：每行不再固定显示一整排操作按钮，行高由约 112 dp 降到约 75 dp，一屏能看到更多会话。
  - 次要操作收进行尾「⋯」菜单：重载扩展、重启 Pi 进程、改名 / 装扮、移动到分组、关闭会话；长按整行同样可以唤起该菜单。
  - 排序模式下行尾直接显示「↑」「↓」，菜单内额外提供「置顶本组」「置顶 / 取消置顶」。
  - 头像从 36 dp 缩到 30 dp，行内间距与上下留白一并收紧；点头像仍是快捷改装扮，点行其余区域仍是打开会话。
- 顶部操作提示（如「已更新「x」装扮与名称」）改为小字单行、上下 8 dp，不再独占一大块高度；分组标题行同理收紧。
- 沿用已有签名，可覆盖安装旧版。

## 验证限制

- Android 构建及 JVM 单元测试（191 个用例）通过，APK 签名与固定证书摘要一致。
- 仅做了编译与单元测试层面的验证，尚未在真机或模拟器上目视确认新行高、长按菜单与排序模式箭头；大字体、超长标题/路径的换行表现仍需真机确认。
