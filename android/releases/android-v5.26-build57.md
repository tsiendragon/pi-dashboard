# PiDash Android 5.26 · build 57

Debug 预发布版；实际手机与完整页面仍待验收。

## 紧凑标题栏与 Material 3 控件

- 机器页、会话列表标题栏隐藏版本号，版本仍可在设置页查看。标题内容区最小 48 dp，保留系统安全区及 48 dp 图标触控目标。
- 列表的连接状态收为紧凑一行；只读说明移至信息按钮，连接错误仍直接展示。机器列表移除重复的介绍文案，减少标题到列表之间的留白。
- 筛选和分组统一使用 Material 3 Chip，主色表示选中，使用一致的圆角与底色；大字号/窄屏自动换行，不压缩触控目标。
- 新建/添加改为一个带图标及文字的 Material 3 扩展悬浮按钮，主色低阴影，移除标题栏重复的新建操作；补齐显式可访问名称。
- 搜索提示收为「搜索会话」，仍支持标题、路径、模型、分组及标签；没有改变登录/断开、只读打开、排序限制或启动逻辑。
