# PiDash Android 5.35 · build 66

Debug 预发布版，保持原有稳定签名；尚未完成真机验收。

## 一体式输入胶囊

- 输入区改成单个圆角胶囊：左侧「＋」、中间输入框、右侧发送按钮都在容器里，不再是“加号 + 灰框 + 外面一个圆按钮”三件套。
- 发送按钮仍按真实条件启用：无草稿/附件/引用/批注、缓存视图或忙碌时禁用；点击逻辑、失败保留草稿、附件清理时机未变。
- 加号菜单内容不变：上下文占用、模型、思考强度、快捷提示、图片/文件、投递方式；投递方式非默认时在胶囊上方显示「投递方式：引导/排队」。
- 去掉输入框右侧常驻的「N 字」计数，避免在窄屏挤压正文；原无障碍朗读文案随之一并移除。
- 胶囊 24 dp 圆角 + 1 dp 发丝边框，暗色下也能看出输入区域；文字仍用 15 sp 正文字号，随系统字号缩放，多行时胶囊增高、超过上限后内部滚动。
- 键盘弹出后仍显示模型/思考/快捷辅助行；`imePadding`、导航栏安全区、48 dp 触控与小屏换行保持原样。

## 验证

- 351 项 Android JVM 测试全部通过（0 失败/错误/跳过），39 张截图回归与 Debug APK 构建通过。
- 新增 `ComposerPillTest`：断言加号在输入框左侧、发送在其右侧且都在同一容器内；占位符只在空草稿出现；输入内容回传；空草稿发送禁用；点击发送只触发一次；禁用态仍显示控件。
- 新增明暗、已输入、200% 字号、600 dp 宽屏的胶囊截图并已查看；这是组件级截图，键盘、输入法、真实发送与真机手势仍未验收。
