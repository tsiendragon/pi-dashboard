# Android 5.80 (build 111)

## 图片按需加载

- Live 会话内的图片不再随精简同步传输内联 base64 数据。
- 精简同步中的图片以「图片已省略，点按加载」占位显示，点按后通过完整详情加载取回图片。
- 其他精简同步行为保持不变；需要查看完整思考、工具参数和输出时，仍可加载完整记录。
- 实测单会话 compact 数据体积从 4.43MB 降至 0.20MB，显著减少同步流量。

## 后端传输优化

- `turn_end` 消息中的冗余 `context` 字段已由后端剥离。
- 此项优化在后端生效，旧版 App 也会受益。

## 说明

- 图片占位依赖新版 Dashboard 的精简同步投影；需要更新并重启 Dashboard 后覆盖安装 APK。
- Debug 预发布，尚未完成真机验收。
