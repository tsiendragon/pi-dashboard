# PiDash Android 3.6 · build 17

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：目标（goal）只读视图

- 会话菜单「目标…」→ 对话框展示 `goal-state` 锚点：
  - objective、状态（进行中 / 已暂停 / 已完成 / 未标注）
  - 工作项进度条 + 逐项 `✓ 已完成` `◐ 进行中` `! 受阻` `⏸ 暂缓` `○ 待做`
  - 阻塞项：`种类 · 归属 · 标题` 与原因（如 `待用户决定 · 用户 · …`）
  - 当前进展与最近进展
- **两种过期提示**，判定与网页 `shared/src/goal-anchor.ts` 一致：
  1. 状态是已完成但仍有未完成工作项
  2. 未完成且已超过 `GOAL_STALE_MESSAGE_THRESHOLD`（300）条消息没有更新
- 会话头部状态行追加「目标 进行中/已暂停/…」，无需打开对话框即可看到。
- **只读**：App 不改写目标。「用 /goal 修改」只是把 `/goal ` 填进输入框，由 Agent 自己执行。
  没有目标时也会说明，并同样提供 `/goal ` 入口。

7 项单测：计数与百分比、状态标签、两种过期判定与阈值边界、needs_user 统计、标签/图标映射、空目标。
