# PiDash Android 5.15 · build 46

Debug APK 预发布版，尚未完成真机端到端和视觉验收。

## 更新

- 下拉刷新：会话列表和会话详情页都支持下拉刷新（列表刷新本机，详情页刷新当前会话），沿用原有 API，不动后台协议。
- 图片查看：
  - 对话里的附件图片现在点一下即可全屏查看，支持双指缩放、拖动平移、双击在「适应窗口 / 2.5 倍」之间切换。
  - 图片解码从组合期的主线程改为 IO 线程，并按最长边降采样（气泡 1440 px、输入框预览 320 px）；滚动长对话时不再反复解码大图，截图类附件也不会再把内存顶爆。
- 空状态不再是死路：连不上机器、搜索无结果、没有会话三种情况分别给出「重新连接 / 清除筛选 / 显示子 Agent · 刷新列表」按钮。
- 搜索框：换成更短的占位文案，加放大镜图标和一键清除；分组标题不再强制转大写（中文无收益，英文会变形）。

## 验证限制

- Android 构建及 JVM 单元测试（191 个用例）通过，APK 签名与固定证书摘要一致。
- 仅做了编译与单元测试层面的验证，尚未在真机或模拟器上目视确认下拉刷新与内部滚动的冲突、图片查看器的缩放手感与内存占用，以及新空态在窄屏大字号下的换行。
