# PiDash Android 5.41 · build 72

Debug 预发布版，保持原有稳定签名；尚未完成真机验收。

## 在服务器运行（交互式）

- 手机可以直接跑一条需要 TTY 的命令：`getpass` 密码脚本、SSH/REPL 提示，不用再打开电脑。
- 入口两处：
  - 会话菜单「运行命令（交互式）…」：自己输入或「粘贴剪贴板」。
  - 回复里的 `bash` / `sh` / `zsh` / `shell` / `console` 代码块右上角「运行」。`text`、`json` 等代码块没有该按钮。
- 运行页显示会话目录、命令、实时输出与退出码；可「Ctrl-C」「结束命令」，关闭页面会结束进程。
- 「隐藏输入」把输入框改为密码样式；密码只作为键入数据发送，不写入会话、磁盘或审批记录，也不会回显到输出。
- 明说是简化视图而不是完整终端：终端控制序列会被过滤，适合问答式脚本，不适合全屏 TUI。

## 服务端

- 新 WebSocket `/api/exec/ws`：与 WebUI 终端同一鉴权（Live 会话凭据 + 同源校验），在服务端用 `node-pty` 起 `/bin/bash -lc <命令>`。
- 命令、输出、键入都不写日志/磁盘；断开连接即杀进程，不触碰 tmux/Pi TUI。
- 每浏览器身份最多 3 条并发；空闲 15 分钟、最长 60 分钟自动结束；命令 ≤ 8 KiB，目录必须是存在的绝对路径。
- 这是有意的提权面：以 Dashboard 运行用户身份执行，不做沙箱，与 WebUI 终端等价；客户端必须明确点击才运行，通知/锁屏没有入口。

## 验证

- 全部 Android JVM 测试通过（新增 `TerminalTextTest`、`ExecConsoleTest`、`MarkdownRunCommandTest`）。
- 后端 `exec-manager` 测试用真实 PTY 验证：输出流、退出码、键入透传、非法帧拒绝、并发上限与释放、断线杀进程。
- 截图仍只覆盖既有组件；运行页为全屏对话框，未做整页真机验收，`phoneEndToEndVerified` 仍为 false。

## 安装 / 生效

- 覆盖安装 APK。
- Dashboard 后端改动需按用户自己的方式重启 `./run.sh`；旧版本服务端没有 `/api/exec/ws`，App 会提示连接失败而不是假装在跑。
