# PiDash Android 5.13 · build 44

Debug APK 预发布版，尚未完成真机端到端和视觉验收。

## 更新

- 「查看详情 / 本轮记录」页对齐主会话界面的视觉语言：
  - 顶栏改为与会话页同一套节奏：48 dp 返回键、两行标题块（标题 + 状态点、记录数、操作步数），右侧新增状态胶囊。
  - 执行步骤分组不再是一块灰色小条：改成与活动卡「执行步骤」完全一致的样式（浅色底 + 细边框 + 圆角，标题旁带等宽字数胶囊，右侧「展开 ▾ / 收起 ▴」；异常时胶囊转红并在标题行显示失败 / 进行中 / 状态未确认）。
  - 展开后的步骤不再额外缩进，与卡片内的步骤行左缘对齐；分组内容统一用分隔线 + 内边距包裹。
  - 状态胶囊抽成共享组件（活动卡与详情页同一份），避免两处状态样式漂移。
  - 步骤不超过 6 条的记录默认展开，较长的记录默认折叠，长会话仍以回复为主。
- 沿用已有签名，可覆盖安装旧版。

## 验证限制

- Android 构建及 JVM 单元测试（191 个用例）通过，APK 签名与固定证书摘要一致。
- 仅做了编译与单元测试层面的验证，尚未在真机或模拟器上目视确认新顶栏、胶囊配色与分组展开态的排版；大字体、超长标题与超长步骤输出仍需真机确认。
