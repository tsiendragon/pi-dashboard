# PiDash Android 5.13 · build 44

Debug 预发布版，尚未完成真机视觉与真实 sudo/PAM 端到端验收。

## sudo 授权：先看懂，再批准

- 弹窗重排为执行说明、可读实际命令、目标机器与目录、密码输入；固定标题及底部取消/授权按钮，中间内容可滚动。
- 命令由难读的原始 JSON 改为带参数边界的阅读预览；原始 argv 可展开精确核对，长参数不截断。空参数、引号与控制/双向文本字符不会被静默隐藏。预览只供阅读，实际执行仍绑定宿主原请求，不解析 UI 文本。
- 配套 `sudo_exec` 新增必填 `reason`：说明命令做什么、为什么需要 root、影响什么。App 明确标注说明来自 Pi，不代表系统验证的安全结论；缺少用途说明、无效命令或过期请求无法批准。
- 沿用应用主题、字号与触控尺寸，减少常驻说明墙；密码与权限的详细说明可展开。保留 HTTPS、单次授权、密码不持久化及生产授权窗口防截图策略。

## 生效

- 覆盖安装新版 APK，使用本次更新的本机 `pi-tsien-live-session` 扩展源码并在 Pi 执行 `/reload`，再重新发起 sudo 请求。旧请求不要直接批准，应取消后补充说明重新申请。
- 本次无 Dashboard 后端或前端代码修改；若已运行支持 5.10 sudo 通道的服务，无需为此重启。仍在更旧服务上时，由用户执行 `./run.sh`（或自己的启动方式）更新服务，agent 不代为部署或重启。
- 配套本机扩展源码提交：`pi-tsien-extension@1c6cb534d881aca4a382b85d0272803ce3b7f504`。扩展来自独立仓库，本 APK 的发布不等于扩展已推送远端或发布 npm。
