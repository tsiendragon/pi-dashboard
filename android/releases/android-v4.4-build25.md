# PiDash Android 4.4 · build 25

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：默认「只看回复」的活动视图

之前默认把整份记录铺出来：用户消息、思考、每一步工具、参数 JSON、回复全都在一屏里，
手机上读不过来。现在默认视图与网页 Dashboard 的活动时间线一致：

- **每轮一张卡**：用户提问一行（灰、最多两行）→ 工具调用折叠成一行
  （`⌄ 3 个步骤 · 已回复 · bash · read`）→ **只显示 Agent 的正文回复**（Markdown）。
- 默认不显示：思考（折成「思考 N 段」）、中间态助手文本、工具参数、重复结果、错误细节（只在有错时一行红字）。
- 点步骤行 → 该轮**完整记录**（每一步的参数与输出都在，什么都没删，只是不是默认）。
- 事实行右侧新增 `只看回复 ⇄ 完整记录`，整页切换，选择按机器+会话记忆；菜单里也有同样一项。
- **表格修复**：单元格不再换行挤压，改为列宽按内容、整表横向滚动（截图里"问题/证据"两列被压扁的问题）。
- 事实行只显示模型 id（不再 `provider/model` 挤成两行）。

投影规则抽成纯函数（`activityReplies` / `activityTools`）并有 3 项单测：
只取非中间态、非错误的助手正文；被打断的一轮回退到最后一段文本；工具按顺序统计。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置与配对。
