# PiDash Android 5.14 · build 45

Debug APK 预发布版，尚未完成真机端到端和视觉验收。

## 更新

- 第一次给整个 app 一套统一的动效语言（150 ms 反馈 / 220 ms 内容 / 260 ms 翻页）：
  - 执行步骤、思考过程、详情页分组的展开与收起不再瞬间跳变，改为高度缓动 + 淡入淡出，外层卡片同步自适应高度。
  - 进入会话从右侧滑入并淡入，返回列表时反向退出；不再是生硬的整屏替换。
- 把字符画的图标换成矢量图标：`⌃ ⌄ ▾ ▴ › ✓` 全部替换为 chevron / 下拉箭头 / 勾选图标，所有「展开 / 收起」提示收成同一个组件，基线和对齐不再随字体漂移。
- 操作反馈：
  - 长按会话行唤起菜单、发送消息、点「最新」都有触感反馈。
  - 结果提示从「输入框上方一行不会消失的小字」改为自动消失的 Snackbar；置顶和排序调整支持「撤销」一步回退。
- 会话页新增「最新」悬浮胶囊：向上翻阅历史时出现，点击平滑回到底部最新内容。

## 验证限制

- Android 构建及 JVM 单元测试（191 个用例）通过，APK 签名与固定证书摘要一致。
- 仅做了编译与单元测试层面的验证，尚未在真机或模拟器上目视确认动效时长、Snackbar 位置与手势重叠、以及矢量图标在大字体下的观感；触感强度也需要真机手感确认。
