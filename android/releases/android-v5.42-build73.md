# PiDash Android 5.42 · build 73

Debug 预发布版，保持原有稳定签名；尚未完成真机验收。5.41 的功能不变，本版是同一功能的正确性修复。

## 修了什么

- **关闭页面真的会结束命令**：之前只杀外层 `bash`，`sleep`、`tail -f`、`ssh` 等子进程会变成孤儿继续跑；现在结束整个进程组（先 SIGHUP，2 秒后 SIGKILL），空闲/超时/断线同样处理。
- **断线不再假装还在运行**：网络中断、代理超时或服务端旧版本关闭连接时，页面会显示「连接已断开，命令可能已经结束」，而不是一直停在「运行中」。
- **旧服务端/无权限给出人话**：`404` 提示服务器版本不支持该接口；`401/403` 提示重新配对，而不是抛出英文异常。
- **输出不再吞首帧**：命令一启动就打出的提示（例如 `Password:`）不会因为订阅晚一步而丢失。
- **转义序列跨分片不再露字符**：颜色/光标码被拆成两次读取时，不会短暂显示 `[3` 之类的字节；同时按分片清洗，长输出不再每帧重扫 200 KB。
- **200% 字号可滚动**：待运行页面内容可滚动，「运行」不会被挤出屏幕。
- **没有工作目录时明确禁用**：会话未上报目录时按钮置灰并说明原因，不再等点了才报错。

## 服务端

- `/api/exec/ws` 与 5.41 相同（Live 凭据 + 同源校验，`node-pty` 起 `/bin/bash -lc`，不写日志/磁盘）。
- 新增输出背压：未送达字节超过约 4 MB 时丢弃并只提示一次，命令本身继续运行。
- 命令、输出、键入仍不落盘；每个身份最多 3 条并发；空闲 15 分钟、最长 60 分钟。

## 验证

- 后端：`exec-manager` 测试新增「杀进程组」回归用例（起 `sleep` 子进程，断开后断言 shell 与子进程都消失）；全量后端测试通过。
- Android：新增 `ExecFrameTest`、`TerminalTextBuffer` 分片/上限用例；`ExecConsoleTest` 覆盖输入、隐藏输入、Ctrl-C、结束、失败与关闭。
- 仍未做整页真机验收，`phoneEndToEndVerified` 保持 false。

## 安装 / 生效

- 覆盖安装 APK。
- 后端有改动：需要按用户自己的方式重启 `./run.sh` 才生效（旧进程仍是 5.41 的行为）。
