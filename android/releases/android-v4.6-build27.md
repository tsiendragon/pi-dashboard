# PiDash Android 4.6 · build 27

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：设备配对已移除，改为访问令牌登录

App 不再有「手机配对」这一层：没有一次性码、没有 3 分钟有效期、没有独立的「设备身份」。

**怎么连**（需要同版本后端）
1. WebUI 侧不再有「手机配对」按钮（配对接口已从后端删除）。
2. App 机器列表 → 该服务器右侧菜单 → **登录** → 粘贴这台机器的访问令牌。
   令牌在 `~/.pi/agent/run/pi-dashboard/live-control-token`（0600，64 位十六进制，首次启动自动生成），
   与网页登录用的是**同一个**令牌，所以不存在第二个可以转让的秘密。
3. 登录成功后服务端返回 HttpOnly `pi_live_session` Cookie，**App 只保存 Cookie，不保存令牌**。

**会话多久失效**：Cookie 是滑动 7 天——在用就一直有效，连续 7 天不用才过期，届时重新粘贴一次。
「断开」只注销这台机器的 Cookie、关闭它的 WS 并释放租约；要一次收掉全部会话，轮换令牌文件即可（网页也要重新登录）。

**代价（明确记录）**
- 令牌若被拿到，等于拿到任何设备都能用的登录凭据；撤销方式只有轮换令牌，且会连带所有会话。
  换来的是：没有配对状态机、没有短期凭证泄漏面，也没有「网页生成 → 手机输入」这两步。
- 机器菜单里原来的「配对 / 解除配对」变成「登录 / 断开」，失败提示改为「需要重新输入访问令牌」。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置与**已有 Cookie**，
  所以升级后已登录的机器仍然可用（旧配对会话在服务端同样有效，只是 12 小时改成滑动 7 天）。
