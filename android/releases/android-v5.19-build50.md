# PiDash Android 5.19 · build 50

Debug 预发布版；没有任何可见的界面重排，这一版是在收口设计系统，防止前面几轮的打磨被后续改动慢慢磨回原样。

## 统一设计令牌

- 全文替换 `MaterialTheme.typography.*` 为项目自己的 `PiType.*`（84 处），两种写法今天指向同样的字号，但只有一个是真的；以后调字号不会再出现「改了一处、另一处没变」。
- 所有颜色字面量收进 `ui/theme`：新增 `CodeColors`（明/暗两套语法高亮配色），Markdown 代码块不再自带调色板。
- 脚注与 caption 字号开启等宽数字（`tnum`）：步数、耗时、百分比、用量这类数字变化时不再左右跳动。

## 让约定可以被检查

- 新增「设计系统」预览（Type scale / Colour roles 两张），在 Android Studio 里一屏看完字号、字重、状态色、圆角与代码高亮，不必切三个界面比对。
- 新增 3 个 JVM 守护测试，违反约定会直接失败：
  - 业务代码里不允许再出现 `MaterialTheme.typography.`
  - `ui/theme` 以外不允许出现颜色字面量
  - 不允许再用 `⌃ ⌄ ▾ ▴ ›` 这类字符当图标

## 验证与限制

- Android 编译通过；JVM 单测 **209 项**（原有 206 + 新增 3 项守护测试）全部通过。
- 仍无真机/模拟器视觉验收；截图回归（Paparazzi/Roborazzi）需要联网引入新依赖，本轮未做，先用预览 + 守护测试兜住最容易被破坏的三条约定。
