# PiDash Android 4.5 · build 26

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：标题栏收窄、自动隐藏，活动变成卡片

三件都是"把屏幕让给正文"：

**标题栏 52 dp，会自己收起来**
- 只剩一行 16 sp 半粗标题 + 一行 12 sp 事实（状态 · 模型 · 目标），去掉了 17 sp 两行标题和独立事实行。
- 向上滚动超过 24 dp 立即收起（滑出 + 收缩动画），回到顶部自动出现。
- cwd 等细节不再占常驻空间。

**一张卡 = 一轮活动**
- 卡片内容只有三样：`状态 + N 步`、提问一行（灰、省略号）、回复**三行预览**（去 Markdown 标记的纯文本）。
- 点卡片 → 全屏「本轮记录」：每一步的参数与输出、思考、完整正文；引用 / 批注 / 分叉都在里面。
- 卡片间距 8 dp、圆角 10 dp、分组色填充，一屏能看 3–4 轮。

**状态说人话，并且实时更新**
- `思考中 / 回复中 / 读取文件 / 写入文件 / 执行命令 / 搜索 / 运行代码 / 调用 X / 已回复 / 失败`。
- 正在跑的工具优先（`bash` → 执行命令，`read` → 读取文件，`write/edit` → 写入文件，`grep` → 搜索）；
  Live 的 WS 快照到达就重算，所以卡片上的动词会跟着 Agent 动。
- 运行时 6 dp 圆点呼吸（全 App 唯一的动画），失败时状态变红。

**输入区回到一行**
- 投递方式（默认/引导/排队）移进「＋」菜单，选中项打勾；只有非默认值或正在输入时才多一行 12 sp 脚注。
