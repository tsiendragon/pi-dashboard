# PiDash Android 5.23 · build 54

Debug 预发布版；尚未完成真机验收。

## 可以自己选深浅色了

- 「设置 → 显示」新增「外观」：跟随系统 / 浅色 / 深色，默认跟随系统；之前只能跟系统走。
- 选择固定档位后，页面与状态栏、导航栏图标一起切换（浅色页面配深色图标，反之亦然），不会出现「深色页面加黑色状态栏图标」。
- 选择会持久化，重启后保留；只影响本 App，不改系统设置。
