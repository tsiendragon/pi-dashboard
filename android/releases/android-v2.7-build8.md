# PiDash Android 2.7 · build 8

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 修复：正文里的路径点不动

2.6 只接上了 `MarkdownRenderer` 的 `onFileOpen`，而那个回调**只对代码片段 `<code>` 和本地链接生效**，
普通句子里写的路径依然没反应。本版把点击解析委托到渲染页根部：

- 代码片段 / 本地链接照旧
- 普通正文里形如 `路径/文件名.扩展名` 的片段也可点击（会去掉尾随标点）
- 外部 `http(s)` 链接仍然不打开，渲染页不跳转
- 原生侧白名单不变：**路径必须出现在当前已渲染正文里**才允许读取

代码块/链接现在也显示为可点样式（`cursor: pointer`）。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置。
- 仍需原有私有 HTTPS 入口授权 + 网页一次性配对码；下载 APK 不等于取得服务器权限。
- 配对身份 30 天那条需要重启一次 Dashboard 才生效。

## 已验证与限制

- 77 项 Android JVM 单元测试通过；APK 构建、包版本、签名核验通过。
- 真机点击行为仍待验收：若某段文字仍点不动，请告诉我你点的**原文片段**（不要发文件内容），
  我据此再放宽或收紧解析规则。
