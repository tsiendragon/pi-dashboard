# PiDash Android 3.7 · build 18

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：后台命令面板

- 会话菜单「后台命令…」（有任务在跑时显示 `后台命令（N 运行中）…`）：
  - 任务芯片按启动顺序排列，选中一个查看详情。
  - 详情：`taskId · status · 耗时 · pid`、命令、exit 码/原因/错误、输出尾部（等宽可滚动，标「已截断」）。
  - 数据来自 Live WS 的 `live_feature_snapshot`（feature `background-commands`），只取最新一次快照。
- **唯一写操作**：把仍在运行的**前台**调用转入后台（`feature_command` → `background`）。
  它和网页一样需要租约，所以会先取控制权；他端持有时直接失败，不抢占。
- **取消不支持**：Live 协议只放行 `background`，`cancel` 只在网页/扩展通道里。对话框内已写明。

5 项单测：最新快照胜出、忽略其他 feature、坏快照不崩、只有运行中前台可转入后台、耗时按结束时间计算。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置与配对。
- 仍需原有私有 HTTPS 入口授权 + 网页一次性配对码。
