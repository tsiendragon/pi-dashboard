# PiDash Android 5.5 · build 36

Debug APK 预发布版，尚未完成真机端到端和视觉验收。

## 更新

- 收紧 Live Pi「完整」视图的消息与步骤间距，用户消息使用较柔和的气泡并限制宽度。
- 用户与助手消息的引用、批注、分叉、全文和思考等次要操作按内容收进消息旁的「⋮」菜单；独立思考记录和步骤组仍可直接展开。执行中与失败状态继续显示。
- 保留系统与 App 字体缩放和操作触控区域；沿用已有签名，可覆盖安装旧版。

## 验证限制

- Android 构建和 JVM 单元测试通过；尚未在真机或模拟器进行视觉及端到端验收。请重点检查窄屏、大字体、明暗模式、长正文及消息菜单。
