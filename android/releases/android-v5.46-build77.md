# PiDash Android 5.46 · build 77

Debug 预发布版，保持原有稳定签名；尚未完成真机验收。本版修复活动列表的状态误判，无后端改动。

## 问题

「活动」里每张卡片左下角都显示 **待确认**，即使回复已经完整显示。

## 原因

Pi 的最终回复经常是 `[思考, 正文]` 内容结构。App 的投影逻辑把**任何包含思考片段的消息**都标记成了「中间步骤」，而判断「这一轮是否已回复」时又排除了中间步骤，于是最终回复永远不算数，所有活动都停在待确认。

## 修复

- 中间步骤现在只包括：**发起工具调用**的消息，或**没有正文**的纯思考消息。
- `思考 + 正文` 正常视为最终回复，活动状态变为「已回复」。
- 工具调用前的进度说明即使带正文，仍因为带 `toolCall` 而保持中间步骤，不会假装完成。
- `commentary` 频道仍不算最终回复。
- 活动卡里的回复内容、顺序、失败/运行中判断不变。

## 验证

- 新增用例：`[thinking, text]` 最终回复 → 已回复且出现在活动回复里。
- 新增用例：带正文但发起工具调用的进度消息 → 不算最终回复。
- 原有 commentary、部分回复、中断工具、失败等用例继续通过；全部 Android JVM 测试通过。
- `phoneEndToEndVerified` 仍为 false。

## 安装

覆盖安装 APK 即可；无需重启服务或重载扩展。
