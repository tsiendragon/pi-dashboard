# PiDash Android 4.1 · build 22

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：极简主义重做

上一版是「有设计系统但元素多」。本版把装饰全部去掉，只用一种手段表达层级：**字号 + 字重 + 不透明度**。

去掉的东西
- **pill 底色**：状态、模型、思考、上下文、标签都不再有胶囊；合并成一行 `running · dashscope/… · 4.2%`。
- **卡片边框**：机器卡片不再是带边框的卡片，是一段标题 + 一行等宽来源 + 一行事实。
- **分隔线**：会话列表行、头部下方、工具组下方全部去掉；分组只靠留白。
- **彩色状态点**：5 dp 点只在「运行中 / 失败」时出现；静态状态只写一个字。
- **用户气泡**：改为右对齐 + 2 dp 细线标记，不再用色块。
- **代码块边框与头部横线**：语言标签变成块上方 11 sp 灰字，`复制` 同行右侧的文字；块底只留 55% 表面色。
- **表格外框**：只保留表头下一条细线。
- **输入区的状态行**：仅在运行/接管时出现，其余时候输入框上方什么都没有；`默认/引导/排队` → `投递：默认` 一行文字。

保留的东西
- 单一强调色，只用于可操作项和运行中状态。
- 四档字号（15/16、13、12、11）与三档不透明度（100/85/75%），正文行高 24 sp。
- 更松的纵向节奏（8/12/16/24/32），同色背景无 elevation。

设计稿 `docs/design-preview.html` 已整体换成极简版，含会话页、机器、会话列表三段，可切明暗。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置与配对。
