# PiDash Android 3.3 · build 14

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：文本文件与 PDF 附件

输入框「＋」现在分两项：**图片（相册）** 和 **文本文件 / PDF（系统文件选择器）**。

- **文本文件**：`md` `markdown` `json` `jsonl` `py` `yaml` `yml` `toml` `ini` `conf` `cfg` `csv` `tsv`
  `txt` `log` `sh` `ts` `js` `sql` `xml` `html` `go` `rs` `java` `kt` `c` `h` `cpp` `rb` `php` `lua`
  `tf` `gradle` `properties` `diff` `patch`。
  - 最多 3 个；单文件 32 KB、合计 96 KB；超出按上限截断并在消息里写明「已截断」。
  - 内容作为 `文件：name.csv（2.1 KB）` + 围栏代码块前置到消息。**手机文件不在 Agent 机器上**，
    所以不走网页那套「只发路径」。
  - 含 NUL 或大量控制字符的二进制直接拒绝，不猜测编码。
- **PDF**：`PdfRenderer` 把**前 4 页**渲染成图片部件（白底、1240 px 宽、JPEG 80）随消息发送，
  与图片共用 4 张 / 单张 3 MB / 合计 6 MB 上限。不需要后端改动，也不把 PDF 上传到服务器。
- **图片**：维持 3 MB × 4 张、PNG/JPEG/WebP/GIF，超限本地缩放重压。
- 附件芯片逐个可移除；发送失败时草稿、附件、引用、批注全部保留。

## 已知限制

- PDF 只发前 4 页（受图片部件上限约束）；扫描件按图片识别，不做 OCR。
- 文本按 UTF-8 解码，GBK 等非 UTF-8 文本会被判为二进制而拒绝。
- 尚不支持 `.docx`/`.xlsx`/`.zip` 等二进制文档。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置与配对。
- 仍需原有私有 HTTPS 入口授权 + 网页一次性配对码。
