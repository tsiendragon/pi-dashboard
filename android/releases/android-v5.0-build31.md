# PiDash Android 5.0 · build 31

Debug APK 预发布版，尚未完成真机端到端和视觉验收。

## 更新

- 统一 App 的明暗主题、文字层级、按钮和分组卡片样式；使用系统字体缩放，不限制用户设置。
- Live Pi 的模型、思考强度和快捷提示合并为一行，减少常驻输入区高度；快捷提示不会覆盖已有草稿。
- 收紧活动详情、普通 Chat 和机器、会话及服务器页面的间距，让正文和列表显示更多内容；保留主要操作和状态信息。
- 普通 Chat 消息时间与正文同行换行，避免给每一行预留时间列。

## 安装与验证

- 包名 `com.sam.pidash`，minSdk 26，沿用已有签名，可覆盖安装。
- 已进行 Android 构建和 JVM 单元测试；未进行真机或模拟器视觉、不同屏幕尺寸、字体缩放、深色模式及端到端验收。
