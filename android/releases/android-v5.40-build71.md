# PiDash Android 5.40 · build 71

Debug 预发布版，保持原有稳定签名；尚未完成真机验收。

## 审批与撤回留痕

- Dashboard 新增只读决策日志：扩展请求的允许/拒绝/回答/取消、sudo 授权、排队撤回都会记录时间、决定、类型、请求标题与来源浏览器短 ID。
- 日志追加到 `~/.pi/pi/live-session-audit.jsonl`（0600；超过 2 MB 在下次启动时轮转为 `.1`），重启后仍可查看；删除文件即清空历史。
- 不记录密码、sudo 完整 argv、排队消息正文；请求标题截断到 120 字符。
- 新接口 `GET /api/live-sessions/:id/audit?limit=...`（只读，需登录）。
- Android 会话菜单新增「审批与撤回记录（只读）…」：按时间倒序显示决定、类型、时间、来源、标题/剩余条数；加载失败显示原因，空记录与失败是两种不同状态。

## 验证

- 全部 Android JVM 测试通过（新增 `AuditListTest`：标签映射、空态/失败态、200% 字号、明暗截图、服务端 JSON 解析）。
- 后端新增 `live-session-audit.test.ts`：持久化重载、按会话过滤、损坏行忽略、标题截断、允许/拒绝/撤回/sudo 记录的注册表行为，并断言日志中不含密码。
- 扩展与前端相关测试通过；Web 端「审批记录」弹窗新增 3 项测试。
- 截图仅覆盖组件；`phoneEndToEndVerified` 仍为 false。

## 安装 / 生效

- 覆盖安装 APK。
- Dashboard 后端改动需按用户自己的方式重启 `./run.sh`（日志文件会在此后开始累积）。
- 旧审计为空属正常：升级前的决定不会被追溯补写。
