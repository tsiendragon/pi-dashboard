# PiDash Android 5.43 · build 74

Debug 预发布版，保持原有稳定签名；尚未完成真机验收。

本版只改设置页和本机偏好，**没有后端改动，不需要重启 Dashboard**。

## 设置页新增

- **显示**：保留外观与字体大小；新增「代码字号」，只放大代码块、工具输出和运行页，正文不受影响。
- **输入**：新增「发送后收起键盘」；只在消息成功交给服务器后收起，失败时保留草稿与键盘。
- **新会话默认**：默认投递方式（跟随服务器 / 立即引导 / 排队）、默认模型与思考强度。只预填新建 Live 会话的输入，不覆盖已有会话。
- **本地缓存**：开关离线缓存正文、3/7/30 天保留期、显示占用与最近写入时间、清除缓存（需确认）。关闭后不再读写新缓存，已有文件保留到手动清除或过期。
- **服务器**：点一行即可编辑名称/地址/凭据并测试连接、在浏览器打开；删除服务器前二次确认。改地址或凭据会清除本机 Live 授权，需要重新配对；会话仍在服务器上。
- **通知**：总开关下可分别关闭「会话完成」与「需要我回答/审批」，支持免打扰时段（可跨午夜）和「通知里隐藏会话名称」。锁屏始终只显示不含会话名的公共版本。
- **关于**：版本与 build、查看新版本（GitHub Releases）、开源许可、导出诊断信息。诊断只包含版本、Android 版本、服务器 origin、连接状态、缓存用量和通知开关，**不含会话内容、凭据、路径或服务器名称**。

## 未包含（需要单独做，避免这次改动过大）

- 消息密度、时间戳显示开关、移动网络下不加载图片：这些会改变会话正文的阅读排版，需单独设计并做整页字号/窄屏验收。
- 应用锁（生物识别）：属于独立安全功能，不在设置页补全范围内。

## 验证

- 新增设置偏好持久化、非法值回退、免打扰跨午夜、缓存统计/清空、诊断脱敏测试。
- 设置卡片新增明暗截图；全部 Android JVM 测试通过。
- 设置弹窗中的文本输入在 Robolectric 下会触发 Compose 布局超时（既有测试环境限制，`AddBackendDialog` 同样未做 UI 测试），因此该弹窗以真实设备行为为准，未纳入截图；组件/交互测试覆盖其余卡片。
- `phoneEndToEndVerified` 仍为 false。

## 安装

覆盖安装 APK 即可；本版不要求重启服务或重载扩展。
