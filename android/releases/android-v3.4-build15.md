# PiDash Android 3.4 · build 15

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：会话树 / 子 Agent 汇总

- 会话菜单新增「会话树 / 子 Agent…」，调用只读 `GET /api/session-tree?file=<sessionFile>`（用会话摘要里的真实路径，
  不猜）。
- 不画 Cytoscape 画布，而是把 `forkOf` 关系投影成**缩进树**：父在 0 层，分叉出来的会话前缀 `└`，
  每行显示工作目录短名、条数、`运行中`、`分叉点 xxxxxxxx…`、`N 个子 Agent`。
- 当前会话用主色标出；`partial`（只解析了尾部）会标明「仅尾部」；`truncated` 在图标题处提示。
- 孤儿（父不在结果里）与环不会被丢弃，会作为根显示；请求失败直接显示原因，不缓存假数据。

纯函数 `sessionTreeRows` 有 5 项单测：嵌套深度、分叉计数、孤儿兜底、环只出现一次、标签文案。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置与配对。
- 仍需原有私有 HTTPS 入口授权 + 网页一次性配对码。

## 已验证与限制

- 106 项 Android JVM 单元测试通过；APK 构建、包版本、签名核验通过。
- 本视图只做**读**：不切换会话、不中止、不分叉。真机需验收长树滚动与中文路径显示。
