# PiDash Android 5.22 · build 53

Debug 预发布版；尚未完成真机验收。

## 打开会话即视为已读

- 进入某个会话时，它的后台提醒会被撤掉（无论是点通知进来，还是从列表点进去）；不再出现「人已经看过了，锁屏还挂着那条提醒」。
- 通知 id 与撤销共用同一套计算，`Int.MIN_VALUE` 这类极端哈希值也做了兜底。

## 透明度收敛成一把尺子

- 之前界面里散着二十种透明度：0.06 / 0.09 / 0.10 / 0.14 / 0.16 / 0.18 / 0.20 / 0.25 / 0.30 / 0.35 / 0.40 / 0.45 / 0.55 / 0.60 / 0.7 …，谁也说不清 0.14 和 0.16 差在哪，眼睛只会读到「不一致」。
- 现在只剩六个语义档位（`ui/theme/Tokens.kt` 的 `Tints`）：`Tint 10%`（淡底）、`TintSoft 16%`（状态胶囊/运行边框）、`Block 45%`（步骤、思考、表头等填充块）、`Border 35%`（1dp 描边）、`Hairline 20%`（块内分隔）、`Separator 60%`（iOS 细线）。
- 文本不再乘透明度：次要文字直接用 `onSurfaceVariant`，它本身就带层级；之前 `copy(alpha = 0.7/0.75/0.8/0.85/0.9)` 的叠加会让同层次文字深浅不一。
- 加了第 4 条守护测试：主题色一旦用字面量透明度（而不是 `Tints.*`）就会失败。

## 验证与限制

- 编译通过；JVM 单测 **214 项**（新增 1 项透明度守护）全部通过；三张截图基线已按新档位重新录制并复核，状态胶囊观感与原来一致。
- 未做真机验收：透明度调整后各卡片在深色模式下的层次、以及"进会话即清通知"在通知中心里的实际表现，仍需在设备上确认。
