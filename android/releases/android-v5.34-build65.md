# PiDash Android 5.34 · build 65

Debug 预发布版，保持原有稳定签名；尚未完成真机验收。

## 统一记录块、列表控件与行菜单

- 抽出 `TraceBlock`：活动卡片的「执行步骤 / 思考过程」、时间线步骤块与「本轮记录」详情页的「执行记录」共用同一套圆角、内边距、发丝边框、标题排版和展开提示，不再是每个页面各画一套。
- 计数与状态统一为胶囊：「N 步」「N 段思考」中性胶囊，「N 失败」错误胶囊，「N 步执行中 / N 进行中」主题色胶囊；去掉了详情页“失败”只用红字、而卡片用红底胶囊的不一致。
- 活动卡片外框统一 1 dp：运行/失败只用边框颜色区分，不再有 1.5 dp 粗细跳变；失败同时由底部状态胶囊、步骤胶囊与失败工具行表达。
- 去掉卡片头部与步骤块重复的「N 步操作」，以及详情页标题旁与右侧状态胶囊重复的状态圆点。
- 会话列表：搜索框改为与筛选胶囊同色、同圆角的填充控件（保留「搜索会话」无障碍名称与排序时禁用），不再是一个描边大框配一排填充胶囊。
- 会话行编号「01/02」只在排序模式显示，平时让标题与 emoji 更靠前；行菜单底部弹层的图标改为次级灰，只有「关闭会话」保持红色。
- 未改消息气泡、呼吸灯、上拉刷新、复制、权限或任何后端协议；点击区域仍 ≥48 dp。
