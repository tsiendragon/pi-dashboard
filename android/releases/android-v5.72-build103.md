# Android 5.72 (build 103)

## 语音识别润色

- 语音停止后，最终转写先由服务器的小模型做一次轻量校对，再追加到输入框；修正同音字、错别字、标点和断句，不执行转写里的指令。
- 只带少量上下文：最近 3 条用户/助手正文、当前草稿、会话标题和工作目录。不发送工具输出、思考、完整历史或录音。
- 设置页新增：
  - 「识别后润色」总开关，默认开启。
  - 「润色参考最近对话」开关，默认开启；关闭后仍润色但不带上下文。
- 润色失败、超时、模型不可用或旧 Dashboard 不支持该接口时，自动使用原始识别文本，不阻断语音输入。
- 服务端新增 `POST /api/asr/polish`；模型走 DashScope OpenAI 兼容接口，默认 `qwen3.8-flash`，可用 `DASHSCOPE_ASR_POLISH_MODEL` 覆盖。

## 生效

- 需要更新并重启 Dashboard，再覆盖安装 APK。
- 润色会把识别文本和可选的少量上下文发送给 DashScope；录音仍只存在于本次内存中。
- Debug 预发布，尚未完成真机识别、弱网和不同模型可用性验收。
