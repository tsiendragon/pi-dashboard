# PiDash Android 5.45 · build 76

Debug 预发布版，保持原有稳定签名；尚未完成真机验收。本版只改「完整」会话里折叠块的抬头信息，无后端改动。

## 为什么改

5.44 已把「2 个步骤 / 思考行」交替的旧结构折成 **执行记录** 块，但折叠时只显示 `N 步 · M 段思考`，看不出到底跑了什么，长会话仍要靠逐块展开。

## 现在的结构

- 每个折叠的执行记录块，标题下多一行单行摘要：`工具名 · 首个参数`（例如 `read · /home/tsien/repos/pi-matrix/sr…`）。
- 有失败时摘要改用 **第一个失败步骤**（例如 `bash · npm test`），折叠状态下也能看到失败发生在哪条命令。
- 摘要只在折叠时显示，单行截断；展开后由具体步骤行承担，不重复第一行；展开后的内容与顺序完全不变。
- 宽度不足时摘要省略，不会把状态药丸或「展开」挤出屏幕。

## 不变

- 不改会话数据、分组、条目顺序；不是摘要替换原文。
- 无新增权限、配置或后端字段；覆盖安装即可。

## 验证

- `LiveCompleteTranscriptTest` 新增断言：`read · …/src/pi.ts` 与 `bash · npm test`（失败步骤优先）在折叠状态下可见。
- 全部 Android JVM 测试通过（448 tests）；明暗折叠截图与 `full-transcript-expanded.png` 已更新。
- `phoneEndToEndVerified` 仍为 false：真机滚动、折叠与字号仍待验收。
