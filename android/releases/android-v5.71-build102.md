# Android 5.71 (build 102)

## 新增

- Live 输入框左侧「＋」菜单新增「技能…（筛选并插入）」。
- 技能列表支持按名称/描述筛选，点选后把 `/skill:<name> ` 插入草稿开头；已有草稿保留在命令后面，不自动发送。
- 列表覆盖加载、空、筛选无结果和错误重试状态。
- 技能通过 `GET /api/skills?cwd=<会话目录>` 读取；服务端用 pi 技能加载器解析当前 cwd 的项目技能和全局技能，旧后端会退回全局列表。
- 技能查询只读，不申请会话控制权，不记录到审计。

## 依赖与生效

- 项目技能需要先更新并重启 Dashboard；APK 覆盖安装即可。
- 仅安装 APK 时，旧后端只会返回全局技能目录中的技能。
- Debug 预发布，尚未完成真机筛选、软键盘和长技能名验收。
