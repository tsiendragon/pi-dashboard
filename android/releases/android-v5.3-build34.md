# PiDash Android 5.3 · build 34

Debug APK 预发布版，尚未完成真机端到端和视觉验收。

## 更新

- 在「设置 → 显示」中选择小、标准或大字体；跟随系统字体缩放，并保存在本机。
- Live Pi「活动 / 完整」移到顶栏，「目标」移入右上角菜单；窄屏时重载和重启仍可从菜单操作。
- 输入框空白且未聚焦时缩小，聚焦或有草稿时展开，为正文腾出空间。
- 最近访问的 Live 正文及部分工具输出可加密缓存在本机，先行显示并继续与服务器同步；同步前明确标注缓存并禁止发送及控制操作。图片、待处理交互和租约不缓存；这不是完整的离线浏览。模型选项短暂缓存在内存，可手动刷新。
- 沿用已有签名，可覆盖安装旧版。

## 验证限制

- Android 构建及 JVM 单元测试通过；尚未进行真机或模拟器视觉、端到端及 AndroidKeyStore 验收。请重点检查窄屏、大字体、输入展开、缓存提示及身份切换。
