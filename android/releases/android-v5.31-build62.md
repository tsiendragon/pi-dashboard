# PiDash Android 5.31 · build 62

Debug 预发布版，继续使用原有稳定签名；尚未完成真机验收。

## 新增复制整条消息

保留 5.30 的正文、思考、参数、输出等分项复制，同时新增明确的「复制整条消息」：

- 用户/助手消息：在「⋮」菜单选择；正文不受折叠预览限制，助手思考一起复制。普通非紧凑布局也提供该操作，独立思考展开后可复制。
- 活动卡片：底部「复制 → 复制整条消息」，将本轮请求、所有中间/最终回复、思考、工具参数/输出及实际状态按原始顺序复制，不局限于最后一段回复，不跨轮次。
- 工具记录：展开后选择「复制整条」，包含关联的执行前思考、自身思考、完整参数和输出，即便紧凑模式未展开参数正文也能复制。
- 分段标记便于分辨内容，保留 Markdown、空白和重复记录；纯正文单条消息仍直接复制原文。图片以数量及“图片本体未复制”说明替代，不导出图片/base64。
- 只读、未接管或缓存内容也可本地复制；空内容不写剪贴板，空活动整条复制入口禁用。数据范围为当前已加载内容，不恢复服务端/缓存已裁剪、尚未加载或尚未生成的文字。
- 保持系统剪贴板的既有成功/失败反馈；不自动读取/上传剪贴板，不包含授权 UI/密码字段。敏感原文复制后仍受系统/输入法剪贴板规则影响，超大内容失败不静默截断。
