# PiDash Android 3.1 · build 12

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版：工具调用真正收敛成一行，去掉多余视图

- **工具一行式**：每次调用显示 `状态图标 · 工具名 · 参数摘要`（如 `✓ bash  cd /repo && npm test`）。
  参数不再以 JSON 灌进正文；完整输出默认折叠，「展开输出」/「展开 Run Code」才显示。
  一次调用的「发起 + 执行事件 + 结果」按 `toolCallId` 合成同一行，不会再出现步骤条 + 大卡片的重复。
- **移除「WebUI 渲染」「活动进度」两个按钮**：会话页只有一个默认视图。离线渲染页、APK 内 3.7 MB 渲染 assets、
  `vite.native-renderer.config.ts` 一并删除，构建不再依赖 `frontend/` 产物。
- **消息卡按角色呈现**：助手正文无气泡、直接走 Markdown；用户消息靠右着色；错误用 error 容器；
  思考内容需要显式「查看思考」。正文超 12 行或 1200 字折叠为「展开全部正文（N 行）」。
- **Markdown 格式**：标题、围栏代码（块内横滚 + 复制）、列表、引用、表格、分隔线；粗体/斜体/删除线/
  行内代码/链接/转义。图片消息原位显示，不再出现「请在 WebUI 查看」占位文字。
- 文件预览：`.md` 用 Markdown 渲染，其他文件按纯文本等宽显示。

## 已知差距（有意保留）

- 无代码语法高亮配色、无 mermaid 图、无 KaTeX 公式、不解析原始 HTML。这些块以等宽文本出现。
- 长代码块只在块内横向滚动；整页只允许纵向滚动。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；同签名覆盖安装保留配置与配对。
- 仍需原有私有 HTTPS 入口授权 + 网页一次性配对码；下载 APK 不等于取得服务器权限。
- 配对身份 30 天空闲过期需要重启一次 Dashboard 才生效。

## 已验证与限制

- 85 项 Android JVM 单元测试通过（新增工具投影 7 项）；APK 构建、包版本、签名核验通过。
- 真机排版与滚动手感仍需验收。
