# PiDash Android 5.11 (build 42)

Debug 预发布版，尚未完成真机验收。

- 机器会话列表顶部增加明确的「新建会话」文字入口，保留原有 + 按钮。
- Live Pi 会话详情右上角「会话操作」菜单可直接新建同一机器上的 Live Pi。
- Live Pi 列表操作栏与详情菜单新增「关闭会话」，确认后发送专用安全关闭指令；不删除已保存记录，但会中断在途任务。
- 关闭请求不抢占控制权、不自动重试；旧版扩展、非 TUI 或重连中的会话禁用关闭。超时或结果不确定时请刷新列表确认状态。

## 验证

- Kotlin 编译及 JVM 单元测试。
- APK 版本、稳定签名与 SHA-256 由发布工具核验。
- 待真机验证：新建目录选择、关闭确认/取消、运行中会话退出、旧扩展禁用、错误提示和不同字体缩放。

仅更新 App，无需重启 Dashboard；服务器须已支持 Live Pi 启动与 session_shutdown 指令。
不包含服务配置、身份凭证或私有设备数据，不开放 Dashboard 服务。
