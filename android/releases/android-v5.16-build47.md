# PiDash Android 5.16 · build 47

Debug 预发布版；尚未完成真机视觉验收。

## 新建 Live Pi：快捷目录与关键词搜索

- 工作目录为空时直接展示最多 3 个快捷路径，点击填入，选定后收起快捷列表。
- 「搜索全部目录」打开独立选择弹窗，可按项目名或完整路径关键词搜索，忽略大小写；多个关键词须同时匹配，项目名匹配优先。
- 每项同时展示名称和完整路径，路径可换行、不省略，避免同名项目误选；搜索可清空，无匹配时可返回手动输入。
- 合并当前服务器提供的项目候选和允许启动的根目录，同路径去重、项目优先；切换服务器立即清空旧目录与搜索状态，不混用其他机器建议。
- 保留手动绝对路径、加载反馈及错误提示。建议不代表启动授权，服务端仍校验路径、权限和启动结果。

## 数据与生效

复用已有 `/api/live-sessions/repo-candidates` 与 `/api/live-sessions/start-options`，没有新增后台扫描或接口。搜索仅过滤返回的候选，不搜索整块磁盘；项目建议依赖服务器的仓库清单与 `liveSessions.repoRoots`，实际启动权限依赖 `liveSessions.roots`。

已有目录接口的服务只需覆盖安装 APK，无需重启 Dashboard 或重载扩展。若修改服务端配置，由用户执行 `./run.sh` 或自己的启动方式加载；agent 未重启服务。
