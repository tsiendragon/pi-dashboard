# Android 5.79 (build 110)

## 精简同步 / 按需加载

- Live 会话首次同步默认使用精简数据：
  - 最终用户/助手正文完整
  - 思考正文不传
  - 工具参数和完整输出不传
  - 工具名、执行状态、失败标记保留
  - 用「思考内容按需加载 / 参数按需加载 / 输出按需加载」占位
- 会话顶部显示精简提示和「加载完整记录」按钮。
- 点击后切换到完整模式、重新连接该 Dashboard 的 Live socket，并加载完整详情；之后可查看完整思考、命令和输出。
- 完整记录加载失败或过大时保留精简视图，显示错误，不会丢掉会话。
- Web 端仍使用完整数据；本版本不做逐条按需加载，而是按会话切换完整记录。

## 说明

- HTTP `/api/live-sessions/:id` 和 Android WebSocket 使用 `compact=1`；完整模式不带该参数。
- 需要更新并重启 Dashboard 后覆盖安装 APK。
- Debug 预发布，尚未完成真机会话切换和超大记录验收。
