# PiDash Android 4.9 · build 30

Debug APK 预发布版，尚未完成真机端到端及视觉验收。

## 本版更新

- 调整 Live Pi 会话页的文字层级、按钮圆角和间距，减少快捷操作中的装饰性表情；回复正文使用更紧凑的项目字体层级，同时保留系统字体缩放。
- 思考强度弹窗改为紧凑单选列表，先选择再点击「应用」；取消不会更改当前设置。
- 整理会话列表和活动卡片的操作文案，保留已有的重载、重启、排序和详情入口。

## 安装与验证

- 包名 `com.sam.pidash`，minSdk 26；沿用已有签名，可覆盖安装。
- 已运行 Android JVM 单元测试及构建；真机和模拟器的字体缩放、深色模式、窄屏布局和交互尚待验收。
