# PiDash Android 4.7 · build 28

**Debug APK 预发布版**，尚未完成真机端到端验收。

## 本版更新：Live 会话管理、活动视图与模型/思考等级交互

1. **会话列表与详情快捷操作**
   - 会话列表新增「排序」模式，支持同一分组内上移、下移与置本组顶部，顺序通过 `/api/live-session-order` 与网页共享，并保留未在线会话记录。
   - 支持设置会话表情（`emoji`）并在会话列表与详情顶部展示。
   - 会话详情顶部新增「活动 / 完整记录」切换，以及「改名」「表情」「重载」「重启」快捷入口（重启保留二次确认）。
2. **活动视图与追问归属**
   - 活动卡片按实际记录顺序展示进度、工具步骤与回复摘要；记录较多时明确提示省略，点开可查看本轮完整记录。
   - 对齐 WebUI 的引用与批注追问识别：空闲后针对历史回复的引用/批注归并回被引用活动，执行中补充归入当前活动，未获最终回复前状态标为待确认。
3. **模型列表与思考等级选择**
   - 模型选择弹窗支持按服务商分组、搜索模型或服务商，并标记当前使用模型与真实上下文窗口。
   - 思考等级改为整行单选卡片与自定义输入组合，提升手机触控准确性。

## 安装

- 包名 `com.sam.pidash`，minSdk 26；使用现有稳定签名，可直接覆盖安装并保留本地服务器配置与登录 Cookie。

## 已验证与限制

- Android 152 项 JVM 单元测试通过；APK 构建、包版本与签名证书摘要核验通过。
- Web 端相关组件测试与生产构建通过。
- **真机未验证**：需要在手机上实测排序、表情编辑、活动卡片展开以及模型/思考等级切换手势与窄屏排版。
