# PiDash Android 5.18 · build 49

Debug 预发布版；尚未完成真机视觉验收。

## 模型 / 思考强度改为底部抽屉

- 「选择模型」和「思考强度」不再用居中弹窗，改为底部抽屉：标题常驻，列表在抽屉内独立滚动，底部一行「关闭 / 取消 · 应用」。
- 内容本身不变：模型仍按服务商分组、支持关键词搜索与「支持思考 / 200K+ 上下文」筛选，当前模型与已选档位仍有高亮；思考档位仍显示五格强度条。
- 好处是滚动列表不会再被小弹窗的高度限制，也不会在键盘弹起时被顶出屏幕。

## 会话详情空态的说明

- 首次打开会话时显示加载指示器并说明「首次打开需要拉取完整记录」，而不是只有一行「正在同步会话详情…」。
- 会话确实为空时，提示「在下方输入框发一条消息即可开始」，不再让人怀疑是不是没加载出来。

## 与上一版的关系

- 5.17 已发布的内容（系统闪屏、预测性返回、会话行操作底部抽屉）保持不变，本版只在前者基础上继续。

## 验证与限制

- Android 编译通过，JVM 单测 206 项通过；沿用稳定签名。
- 尚未真机验收：抽屉在横屏/分屏下的高度上限（当前 620 dp）、键盘弹出时与输入框的关系、以及模型列表很长时的滚动与拖拽关闭手势是否互相干扰。
