# pi-dashboard UI/UX 页面评审

## 目标与边界

像独立评审者一样检查已有页面：先找影响用户完成任务的真实问题，再给出具体、可执行的改进意见。不要把个人审美偏好说成缺陷，不要猜测看不到的页面状态，也不要默认替用户修改代码。

## 评审前

1. 阅读根目录 `AGENTS.md`，检查 `git status --short`，保留工作区里已有的修改；本技能默认只读。
2. 确认要评审的路由/页面、主要用户和页面任务。查看页面组件、共用组件、状态/数据来源和现有测试，弄清哪些是已知行为，避免把正确的业务流程误报成设计问题。
3. 检查 `frontend/src/index.css`、`frontend/src/themes/` 和页面实际使用的共用组件。判断问题是否违反了本项目已有的主题、组件或交互约定，而不是拿一套外部样式当标准。
4. 如果浏览器或截图可用，先实际查看目标页面。检查常用桌面宽度、窄屏（例如约 390px）和 200% 浏览器缩放；对有多个主题的页面至少看一个明暗主题，并在结论中写清实际覆盖了哪些尺寸、主题和状态。无法预览时，只能报告源码能证明的问题，并明确“未做视觉检查”。
5. 根据页面真实功能检查关键状态：加载、空数据、错误、成功、禁用、长内容，以及关键操作完成或取消后的反馈。只检查当前页面确实存在或能复现的状态。

## 检查清单

### 任务与信息

- 用户能否快速看懂页面用途、重要信息、当前状态和下一步操作？标题、操作、筛选项和字段名称是否清楚一致？
- 用户能否完成主要流程？操作是否有清楚的结果、加载反馈、错误说明和恢复办法？有没有容易误点、无法取消或状态不明的操作？
- 表格、筛选和表单是否适合其真实信息量？关键列和操作是否容易找到；空状态和错误状态是否给出有用下一步？

### 视觉与一致性

- 字号、层级、对齐、间距、颜色和密度是否帮助用户扫描，而不是互相争抢？主要操作是否容易辨认？
- 是否沿用现有主题变量和共用组件？颜色是否在相关明暗/彩色主题中可读？颜色是否被错误地当作唯一状态提示？
- 是否存在无实际用途的装饰、重复卡片、过多阴影/渐变、过重边框或不必要的动画？只把它们列为问题时，说明它怎样影响阅读或操作。

### 窄屏、缩放与内容

- 窄屏下是否出现整页横向滚动、内容互相遮挡、按钮被挤出屏幕或固定栏挡住内容？
- 长标题、编号、URL、标签和连续无空格文本是否会溢出？被截断的信息是否仍可查到？放大到 200% 后布局和操作是否仍可用？
- 触控操作是否容易点到？横向滚动的表格是否有明确提示，或提供更合适的小屏呈现？

### 无障碍与操作

- 只用键盘能否到达并操作重要控件？焦点是否清楚、顺序是否合理？
- 图标按钮和表单控件是否有可理解的名称或标签？提示信息、错误信息是否关联到对应控件？
- 状态是否同时有文字/图标等非颜色表达？如需判断对比度，只有在实际测量后才报告具体数值。
- 动画是否妨碍阅读或操作？是否尊重减少动态效果设置？

### 图表和数据呈现

- 图形是否适合要回答的问题（趋势、比较、构成等），图例、单位、时间范围是否足够清楚？
- 刻度、基线、排序、颜色和标签是否会让人误解数值？截断或汇总是否有说明？
- 只评审呈现方式；除非数据来源和定义可核实，不推断或质疑业务数据的正确性。

## 证据与排序

- 只报告有证据且会影响理解、完成任务、可读性或可访问性的发现。把“确认的问题”“需要更多证据的疑点”和“可选的美化建议”分开。
- 每条问题都写：严重程度（高/中/低）、页面位置或操作步骤、观察到的现象、对用户的影响、具体改进建议。能给截图区域、屏幕尺寸、主题或状态时一并注明。
- 高：阻断主要任务、导致误操作或关键信息不可读；中：显著增加理解/操作成本；低：影响较小但有明确改进价值。不要为了显得全面而凑问题。
- 优先给最重要的 3–5 条建议。先说改善任务、信息和可读性的内容，再说纯视觉偏好；指出现有页面做得好的部分，避免破坏有效设计。

## 输出格式

用中文按以下结构报告：

1. **结论**：整体是否可用，以及最重要的风险。
2. **检查范围**：页面/路由、查看过的尺寸、主题和状态；注明源码检查还是实际视觉检查。
3. **发现**：按高、中、低列出有证据的问题，每条包含位置、影响和改进办法。没有发现时明确说“在本次检查范围内未发现明显问题”，不要声称全站无问题。
4. **优先建议**：列出最值得先做的 3–5 项；区分必须修复与可选优化。
5. **未检查项**：列出无法打开的页面、无法复现的状态或没有实际测量的项目。

默认不写文件、不改代码、不启动或重启 dashboard 服务。用户明确要求“评审并修复”时，先给出评审结论，再使用 `dashboard-ui-ux` 落地已授权的改动；不要顺手扩大到无关页面。
